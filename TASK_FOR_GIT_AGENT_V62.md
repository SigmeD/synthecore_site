## Главная задача

**В существующем Git может оставаться старый вариант сайта и старые анимации. Перенести из приложенного `SyntheCore_v62_Git_Agent_Handoff_v2.zip` ВСЮ согласованную v62, включая новую систему анимаций.** Не оставлять старые JS/CSS-анимации из Git и не пересобирать их самостоятельно.

Наша v62 уже прошла длинный цикл доработки плавной прокрутки и закреплений. В архиве лежит **готовая реализация**, а не инструкция по воспроизведению эффектов с нуля. **Сначала заменить старый код на точный эталон v62; после этого анимации, хедер и футер заморожены.**

## Порядок работы

1. Проверь `git status`, `git branch -vv`, `git remote -v`, текущий `main`. Не считай, что Git уже содержит v62; не утверждай, что там точно v60, пока не сравнил.
2. Создай отдельную ветку от актуального `main`, например `chore/import-approved-v62`. Без прямого коммита в `main` и без force push.
3. **Сделай файловое сравнение** репозитория и распакованной v62; выпиши изменения `index.html`, `js/`, `css/`, `assets/vendor/` и ассетов. Если есть несогласованные более свежие изменения, остановись и согласуй, что сохранять.
4. Перенеси утверждённые файлы из ZIP, **включая** обновлённые `js/hero-scroll.js`, `js/works.js`, `js/services.js`, `js/testimonials.js`, `css/sticky-handoff-v61.css`, `css/v62-services-alignment.css` и все остальные CSS/JS из эталона. Убедись, что `index.html` подключает нужные файлы **в порядке v62**. Не подмешивай код старой анимации из Git.
5. Перенеси точные утверждённые шапку и футер из v62 как часть исходного `index.html`, **но не дорабатывай их**. После импорта шапка, футер и motion-код должны остаться байт-в-байт как в архиве.
6. Проверь `node scripts/verify-v62-import.cjs --strict`: совпадают 437 оригинальных файлов v62, включая `index.html`, 17 motion-файлов и библиотеки. Затем выполни команды тестов из миграционного документа. Любое несовпадение эталона — сообщить и согласовать, не скрывать.
7. Проверь браузерные анимации на десктопе/мобильном, быстрый и обратный скролл и `prefers-reduced-motion`. Особое внимание: **CSS sticky** вместо прежнего GSAP `pin` на трёх блоках, масштабирование **первой** карточки «Работ», `overflow: clip` и нулевой `scrollLeft` у «Услуг», **+30%**, а не +50%, длина анимации отзывов.
8. Создай PR с diff, отчётом статических тестов, подтверждением SHA, скриншотами и видео/описанием прокрутки. **Не выполняй merge/deploy** без моего подтверждения.
