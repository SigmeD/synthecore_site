## Почему первая карточка анимируется именно на входе

Для первой карточки используется свободный участок прокрутки **до** закрепления сцены. Если добавить шестой этап внутри уже закреплённой сцены, посетителю придётся делать дополнительный оборот колеса до появления второго проекта. Теперь первая карточка увеличивается естественно по мере входа в viewport, остальные пять — на прежних пяти закреплённых отрезках. Длина pin и порядок проектов сохранены.

## Браузерные проверки

Исходники в автономном HTML запущены в Chromium/Playwright. Для динамического QA используются внутренние контрольные состояния; сторонние CDN-шрифты в автономной среде недоступны.

- **7 разрешений успешно:** 320×700, 390×844, 840×900, 1024×768, 1440×900, 1920×1080, 2560×1440. Для каждого: нет ошибок JS, горизонтального переполнения; вход первой карточки монотонен, конец входа совпадает с началом pin.
- При 1440 px вход первой карточки: `scale 0.885 → 0.9425 → 1`. При 390 px: `0.9 → 0.95 → 1`. При обратной прокрутке состояние возвращается к исходному.
- Следующая карточка на первом отрезке закрепления: `y 900 → 450 → 0`, `scale 0.885 → 0.9425 → 1`. Движение после достижения цели прекращается.
- Галерея услуг: ровное смещение `x 0 → -325 → -650 → -974 → -1299 px`; после завершения pin остаётся `-1299 px`.
- Программный переход по кнопке увеличил положение скролла через общий Lenis API.
- Цикл изменения ширины 1440 → 840 → 390 → 1200 → 1440 px: переключение режимов и ровно по одному триггеру входа/закрепления Works, без дублирования.
- `prefers-reduced-motion`: Works в статичном потоке, Services в обычной горизонтальной прокрутке, Testimonials в нативном режиме.
- FAQ: раскрытие кнопкой работает.
- Вход первого блока проверен на графических кадрах **до / после** при одинаковом скролле.
- **4K (3840×2160):** попытка полного прогона автономного HTML превысила лимит времени тестового браузера. Не засчитано как пройденный тест.
- `node --check` изменённых JS, проектные статические валидаторы и `node --test scripts/test-static-checks.cjs`: **69/69 PASS**.
