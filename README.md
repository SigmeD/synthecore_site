# SyntheCore

Сайт бюро сложных IT-систем: доработка проектов, автоматизация, интеграции и разработка новых решений.

Согласованная сборка — главная v62 с общими хедером, футером и каталогом v27, детальные страницы Beauty Insight AI, приложения цветов и калькулятора металлоизделий, общий шаблон кейсов v20. Основа зафиксирована в [PR #6](https://github.com/SigmeD/synthecore_site/pull/6), детальные кейсы и кнопки без свечения — в [PR #10](https://github.com/SigmeD/synthecore_site/pull/10), Flowers v2 — в [PR #13](https://github.com/SigmeD/synthecore_site/pull/13), на слияние которого владелец дал отдельное разрешение. На слияние Metal v5 в [PR #12](https://github.com/SigmeD/synthecore_site/pull/12) владелец также дал отдельное разрешение. Публикация ещё не выполнялась.

Названия, краткие описания и метки всех работ берутся из каталога `/raboty/` и автоматически синхронизируются на зависимых страницах. Это общее правило закреплено в [PR #11](https://github.com/SigmeD/synthecore_site/pull/11), включая обе метки в строках главной и модалок.

## Запуск

Из корня проекта на Windows:

```powershell
.\start-local.ps1
```

Или откройте `start-local.bat`. Установка npm-пакетов не нужна.

- Главная: `http://127.0.0.1:4173/`.
- Каталог: `http://127.0.0.1:4173/raboty/`.
- Beauty Insight AI: `http://127.0.0.1:4173/raboty/beauty-insight/`.
- Приложение заказа цветов: `http://127.0.0.1:4173/raboty/flowers/`.
- Калькулятор металлоизделий: `http://127.0.0.1:4173/raboty/metal-calc/`.
- Остановка сервера: Ctrl+C в его терминале.

Для другого порта: `.\start-local.ps1 -Port 4176 -NoBrowser`.

## Документация

Сборка HTML и единого CSS главной: `node scripts/build-site.cjs`. Общая проверка подготовленных файлов: `node scripts/verify-site.cjs`; после коммита — с `--git-ref HEAD`. Исходные CSS остаются модульными. [Аудит и очистка инструментов](docs/REFACTOR_AUDIT.md).

Начните с [навигатора](docs/README.md): запуск, проверки, анимации, принятая сборка и [шаблон детальных кейсов](docs/CASE_TEMPLATE_V20.md). Готовые кейсы автоматически получают основные ссылки на главной, в каталоге и в «Других работах»; у остальных работ остаются модалки.

Перед изменениями прочитайте [AGENTS.md](AGENTS.md). Хедер, футер и анимации заморожены. Изменения проходят через отдельную ветку и Pull Request; слияние и публикация требуют разрешения владельца.

Отзывы на сайте демонстрационные и не являются отзывами реальных клиентов.
