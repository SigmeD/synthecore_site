# SyntheCore

Сайт бюро сложных IT-систем: доработка существующих проектов, автоматизация, интеграции и разработка новых решений.

**В `main` объединена главная v62 с Header v24, Footer v12 и каталогом v27.** [PR #6](https://github.com/SigmeD/synthecore_site/pull/6) слит 21.10.2026 коммитом [`3256e53`](https://github.com/SigmeD/synthecore_site/commit/3256e536615c216fae8a92caa129ca180bd022e3), включая историю [PR #4](https://github.com/SigmeD/synthecore_site/pull/4). [Результат слияния](docs/RELEASE_V62.md). Публикация сайта не выполнялась и требует отдельного разрешения владельца.

## Содержимое

| Маршрут | Содержимое |
|---|---|
| `/` | Hero, аудитории, шесть работ, шесть услуг, три шага, четыре отзыва с маркировкой ДЕМО, семь FAQ и общий футер |
| `/raboty/` | Шесть проектов в сетке с модальными описаниями, общий хедер и футер |

На главной используется утверждённая анимация v62: единый Lenis/GSAP, CSS sticky для Hero/Работ/Услуг, увеличение первой и последующих работ, выровненная горизонталь услуг и дистанция отзывов +30%. На узких экранах услуги прокручиваются нативно; `prefers-reduced-motion` учитывается. Оболочка и каталог сохранены из v27.

## Локальный запуск

Из корня проекта на Windows:

```powershell
.\start-local.ps1
```

Или запустите `start-local.bat`. Порт по умолчанию — **4173**, каталог доступен по `/raboty/`. Установка пакетов и runtime-сборка для просмотра не нужны: готовые HTML, изображения и библиотеки находятся в Git.

Последний проверенный сервер этого сеанса работает на [http://127.0.0.1:4176/](http://127.0.0.1:4176/) и [каталог](http://127.0.0.1:4176/raboty/). Для такого запуска без открытия браузера:

```powershell
.\start-local.ps1 -Port 4176 -NoBrowser
```

В новом сеансе проверьте, запущен ли сервер. Остановка — Ctrl+C в терминале сервера. Папки `output/worktrees/site-v60` и `output/worktrees/works-v27` сохранены как исторические checkout в detached HEAD; они не являются текущей сборкой.

## Ограничения изменений

**Анимации, хедер и футер заморожены.** Новые изменения этих областей требуют отдельного разрешения владельца. Остальной контент меняется только по конкретным заданиям. См. [AGENTS.md](AGENTS.md).

Header/Footer генерируются из `templates/partials/`, страницы — из `templates/pages/`. Если задание разрешает изменение шаблона, затем выполните `node scripts/build-site.cjs` и включите соответствующие готовые HTML в коммит. Самостоятельно обновлять библиотеки, переименовывать файлы v61 или переписывать движение нельзя.

Локальные зависимости — GSAP/ScrollTrigger **3.12.5**, Lenis **1.3.26**. Для оболочки/каталога сохранены локальные Manrope 400/500/600. Защищённый `css/design-system-v61.css` дополнительно содержит исходный Google Fonts `@import`; не считать шрифтовые зависимости всей главной полностью офлайн.

## Проверки

Нужен Node.js. Статические проверки выполняются без браузера:

```powershell
node scripts/verify-v62-import.cjs
node docs/qa/v62-on-v27/verify-git.cjs HEAD
node scripts/build-site.cjs --check
node scripts/check-project.cjs
node scripts/verify-works-static.cjs
node scripts/verify-services-static.cjs
node scripts/check-hero-geometry.cjs
node scripts/verify-sticky-handoff-v61.cjs
node --test scripts/test-static-checks.cjs scripts/test-shared-site.cjs
git ls-files --cached --others --exclude-standard | node scripts/check-doc-links.cjs
```

При работающем сервере можно сверить HTTP-ресурсы: `node scripts/check-project.cjs --http http://127.0.0.1:4176/`.

Целевой контракт: **17 raw motion SHA v62**, **25 файлов оболочки/каталога v27** и неизменённый фрагмент семи секций главной. Исходный архивный `--strict` относится к самостоятельной v62 с другой оболочкой и не является проходной проверкой итогового сайта. Не изменять manifests ради устранения таких расхождений. Для сохранения исходных LF/CRLF используйте `core.autocrlf=false` при checkout/staging защищённых файлов.

Для браузерной QA нужны Playwright и Chromium. Текущие сценарии, адреса, требуемые эталоны и результаты — в [QA v62](docs/qa/v62-on-v27/README.md) и [реестре проверок](scripts/HISTORICAL_CHECKS.md). Исторические `verify-v60-*` и исходные v27-сценарии не следует использовать как готовую приёмку новой главной.

При слиянии подтверждены **75/75** статических тестов, **17/17** motion SHA и **25/25** файлов v27. Полная исходная браузерная матрица: **372/372** движения и **295/295** оболочки/каталога; свежий pre-merge прогон — **139/139** на десктопе и мобильном. Это результаты зафиксированной сборки, а не автоматическое подтверждение последующих изменений. Физическая мышь/тачпад и другие браузеры остаются вне подтверждённого автоматического прогона.
