# SyntheCore

Сайт бюро сложных IT-систем. SyntheCore помогает дорабатывать существующие проекты, автоматизировать рабочие процессы, связывать сервисы между собой и запускать новые решения.

На сайте можно посмотреть примеры работ, узнать об услугах и этапах сотрудничества, найти ответы на вопросы и связаться с командой по электронной почте.

В `main` пока находится v60 из [PR #3](https://github.com/SigmeD/synthecore_site/pull/3), объединённого 16 октября 2026. Подробности новой ветки: [интеграция](docs/WORKS_V27_INTEGRATION.md), [дизайн-система v0.1](docs/DESIGN_SYSTEM_V0_1.md), [приёмка и скриншоты](docs/qa/works-v27/README.md).

## Как открыть сайт на компьютере

На Windows запустите `start-local.bat` из папки проекта. Или выполните в PowerShell:

```powershell
.\start-local.ps1
```

Сайт откроется по адресу [http://127.0.0.1:4173/](http://127.0.0.1:4173/). Если сервер уже запущен, обновите страницу. Остановка сервера — Ctrl+C в его окне.

Каталог открывается напрямую по `/raboty/`. Общие Header/Footer редактируются в `templates/partials/`, страницы — в `templates/pages/`. После изменения выполните `node scripts/build-site.cjs` и сохраните оба готовых HTML в коммит. Проверка актуальности: `node scripts/build-site.cjs --check`. Для запуска без окна браузера используйте `.\start-local.ps1 -NoBrowser`.

Для другой рабочей копии укажите отдельный порт. В текущем сеансе версия PR #4 запущена из `D:\Projects\synthecore\output\worktrees\works-v27` на [4183](http://127.0.0.1:4183/); [каталог](http://127.0.0.1:4183/raboty/). Для повторного запуска из этой папки: `.\start-local.ps1 -Port 4183 -NoBrowser`. При новом сеансе проверьте, работает ли сервер. Основная папка `D:\Projects\synthecore` остаётся на `main`.

Для просмотра сайта не нужны сборка и установка пакетов: все изображения и библиотеки включены в проект. Сайт состоит из HTML, CSS и JavaScript. Он использует локальные GSAP/ScrollTrigger 3.12.5 и Lenis 1.3.26 для анимаций и плавной прокрутки.

## Как проверить работоспособность

Для проверок нужен Node.js. Из корня проекта:

```powershell
node scripts/check-project.cjs
node scripts/build-site.cjs --check
node scripts/verify-works-static.cjs
node scripts/verify-services-static.cjs
node scripts/check-hero-geometry.cjs
node --test scripts/test-static-checks.cjs scripts/test-shared-site.cjs
```

Эти команды проверяют структуру страницы, наличие файлов, целостность изображений и библиотек, а также расчёты первого экрана. При работающем сервере можно дополнительно сверить отданные файлы:

```powershell
node scripts/check-project.cjs --http http://127.0.0.1:4173/
```

Для проверки прокрутки, меню, кнопок и поведения на разных экранах используются браузерные сценарии. Для них нужны установленный Playwright и подходящий браузер. Адрес должен совпадать с портом запущенного сайта:

```powershell
$env:SYNTHECORE_URL = 'http://127.0.0.1:4173/'
node scripts/verify-v60-regressions.cjs
node scripts/verify-v60-browser.cjs
node scripts/verify-works-v27-browser.cjs
node scripts/verify-works-v27-motion.cjs
```

Укажите адрес именно проверяемой рабочей копии: для запущенной версии PR #4 это `http://127.0.0.1:4183/`. Без `SYNTHECORE_URL` сценарии v60 используют 4174, новые сценарии v27 — 4182. Назначение и результаты запусков описаны в [реестре проверок](scripts/HISTORICAL_CHECKS.md).

При приёмке интеграции v27 пройдены **74/74** статических теста, **295/295** браузерных проверок обеих страниц на семи размерах, **268/268** проверок главной на четырёх размерах и **6/6** проверок движения. Методика, JSON, скриншоты, найденные исправления и ограничения Chromium-прогона — в [QA v27](docs/qa/works-v27/README.md). Историческая приёмка v60 (666/666 на десяти размерах, 69/69 статических) сохранена в [QA v60](docs/QA_V60.md); эти числа относятся к исходной v60.
