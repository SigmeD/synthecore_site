# SyntheCore

Сайт бюро сложных IT-систем: доработка проектов, автоматизация, интеграции и разработка новых решений.

Согласованная сборка — главная v62 с общими хедером, футером и каталогом v27. Она находится в `main` после [PR #6](https://github.com/SigmeD/synthecore_site/pull/6). Публикация ещё не выполнялась.

## Запуск

Из корня проекта на Windows:

```powershell
.\start-local.ps1
```

Или откройте `start-local.bat`. Установка npm-пакетов не нужна.

- Главная: `http://127.0.0.1:4173/`.
- Каталог: `http://127.0.0.1:4173/raboty/`.
- Остановка сервера: Ctrl+C в его терминале.

Для другого порта: `.\start-local.ps1 -Port 4176 -NoBrowser`.
