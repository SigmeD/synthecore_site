## Жёсткий запрет без отдельного разрешения владельца

- **Хедер**: весь `header.floating-header` (`#floatingHeader`), меню, логотип, кнопка, любые его CSS/JS/тексты/адаптивы.
- **Футер**: весь `section.sc-footer#contact`, включая CTA, навигацию, волну и связанную разметку/стили/скрипты.
- **Анимации**: Lenis/GSAP/ScrollTrigger, CSS `sticky`, `pin`, `scrub`, `lerp`, `ease`, таймлайны, отзывные карточки в движении, параметры входа/выхода секций, прокрутка, ширина/высота scroll-сцен, `overflow: clip`, начало и конец горизонтальных галерей и межблочные отступы, согласованные с механикой.
- Запрещены: автоматический рефакторинг JS/CSS-анимаций, глобальная нормализация селекторов, удаление скрытых элементов, к которым обращается скрипт, `npm update` или замена библиотек «для порядка», изменение файлов из protected SHA-256 manifest.

**Защищённые 17 файлов перечислены в** `docs/V62_SOURCE_SHA256.json`. Они могут быть перенесены из эталона в Git без модификаций. `css/faq-footer.css` и `js/faq-footer.js` защищены целиком, даже если внутри есть логика FAQ. Правки FAQ оформлять отдельно, не меняя этот код.
