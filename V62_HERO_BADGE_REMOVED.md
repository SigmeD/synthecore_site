# SyntheCore v62 — удаление подписи на фото Hero

Решение: по просьбе пользователя убрать видимую плашку «ИНЖЕНЕРНАЯ РАБОТА / КОНЦЕПТ» с центрального изображения первого экрана.

## Изменено

- `index.html`: текстовый бейдж заменён пустым скрытым узлом `<span class="photo-caption" aria-hidden="true" hidden></span>`.
- Исходный DOM-узел сохранён **только ради совместимости** с утверждённым, замороженным `js/hero-scroll.js`: он читает этот элемент при подготовке анимации и при расчёте позиции. Удалять узел полностью без разрешения менять JS нельзя.
- Само изображение Hero, геометрия, текстовые предложения слева/справа, кнопка и зафиксированные анимации не изменены.
- Старые упоминания бейджа в исторических документах относятся к прошлым версиям и отменены этим решением.

Состояние: v62, точечная правка содержимого. GitHub и production не обновлялись.
