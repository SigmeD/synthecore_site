## Локальный запуск

Рабочая папка: `D:\Projects\synthecore`. Сервер доступен на [http://127.0.0.1:4173/](http://127.0.0.1:4173/).

`start-local.bat` запускает встроенный PowerShell HTTP-сервер и открывает сайт; Python и Node для сайта не нужны. Не запускайте второй экземпляр на занятом порту. После сохранения файлов достаточно обновить страницу, при необходимости — Ctrl+F5. Сервер отдаёт Cache-Control: no-store.

Для другого порта: `./start-local.ps1 -Port 4174`. Остановка сервера в терминале — Ctrl+C.

Пользователь запустил `start-chromium.bat`; подключение к отдельному Chrome 149.0.7827.55 на `http://127.0.0.1:9222` подтверждено. Профиль находится в проекте; личные вкладки и настройки Codex не менялись. Подробности в инструкции Chromium.

## Механика

Hero следует выбранному пользователем Works_v8 HTML: постоянная компактная высота, прежняя композиция, duration1.2, scrub1, pin1.1 высоты окна. Lenis1.3.26 и GSAP3.12.5 работают через один ticker. Контрольная точка ждёт физического конца и завершения scrub; следующий жест разрешает уход Hero. Отдельный ScrollTrigger подтягивает только `.audience-copy` с80–140px до0, scrub0.55, ease:none. Отступы и высоты секций не меняются.

Оригинальное фото раскрывается маской и равномерным transform до границ исходного баннера. Баннера-height tween больше нет. Reverse корректно обращает фото и дополнительное движение списка; клавиатура/якоря/нативная прокрутка не блокируются. На mobile/reduced motion нет принудительных анимаций. Сравнение с переданным HTML, проверки и видео — в актуальном отчёте.

Встроенные Lenis anchors отключены: фильтр обычных якорных ссылок вызывает тот же lenis.scrollTo, сохраняет hash и фокус. Модифицированные клики остаются нативными. При reduced motion, ширине до 850 px или отсутствии точного указателя/hover — статичная фотография и нативная прокрутка. Отказ библиотеки также оставляет рабочую страницу.

## Сохранение дизайна

HTML-контент, типографические размеры, оранжевая палитра, фотографии, 3D-иконки, порядок аудиторий и исходные обработчики меню/карточек сохранены. Во время браузерной проверки исправлены конфликтующие CSS-переопределения: заголовок ниже хедера на низком desktop, внутренние поля mobile и обычная desktop-сетка в reduced motion. Это исправления перекрытий, не новая композиция.

«С кем работаем» сохраняет две desktop-колонки, heading32px/38.4px с отступом36px, лёгкие названия и теги без рамок. По умолчанию категория не выбрана и превью скрыто. Намеренное движение мыши над категорией показывает одну карточку; смена категории плавно меняет содержимое. Уход из общего блока или фактическая прокрутка сбрасывает hover, а неподвижный курсор при скролле не активирует список. Фокус показывает карточку, Escape сбрасывает выбор. На устройствах без hover нажатие открывает карточку, повторное закрывает; выбранную нажатием карточку можно прокручивать для чтения. Иллюстрации слева сверху с мягким оранжевым свечением. При reduced motion анимация отключена; превью работает и без GSAP/Lenis. Три inline-действия «Смотреть» по-прежнему удалены. Изменены только audience-логика js/main.js и scoped CSS блока; Hero и обработчики меню сохранены.

## Проверки

Для команд нужен Node и установленный Playwright; приложение использует только локальные зависимости.

```powershell
node scripts/check-hero-geometry.cjs
node scripts/check-project.cjs
node scripts/verify-hero-gate.cjs
node scripts/verify-hero-gate-edge.cjs
node scripts/check-browser-access.cjs
$env:PLAYWRIGHT_CDP_URL = 'http://127.0.0.1:9222'
node scripts/verify-hero.cjs
node scripts/check-adversarial.cjs
node scripts/capture-reference.cjs
```

Матрица прошла на 1366×768, 1920×1080, 3840×2160, 390×844, 430×932. Desktop: пять стадий раскрытия, остановка колеса, reverse, release, клавиатура, якоря, reduced motion и resize. Mobile: нативный режим, меню и карточки. Отдельно проверены резкое пересечение pin, история, initial hash, настоящий эмулированный touch-жест, ориентация и отсутствие зависимостей. Ошибок JavaScript нет.

Результаты относятся к Chromium и эмуляции viewport/touch. Реальные телефоны, другие движки и формальный FPS/WCAG-аудит не проверялись. Полные доказательства и воспроизводимая запись — в протоколе.
