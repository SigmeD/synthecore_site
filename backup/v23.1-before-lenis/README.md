## Локальный запуск

Рабочая папка: `D:\Projects\synthecore`.

Дважды нажмите `start-local.bat`. Он запускает `start-local.ps1`: встроенный PowerShell HTTP-сервер на [http://127.0.0.1:4173/](http://127.0.0.1:4173/) и открывает браузер. Python и Node.js не требуются. При запуске в терминале остановка — `Ctrl+C`.

Другой порт можно передать параметром существующего скрипта:

```powershell
.\start-local.ps1 -Port 4174
```

14 октября сервер запущен в фоне на порту 4173. Страница по HTTP совпадает с локальным `index.html`. Повторный запуск на занятом порту не нужен. После сохранения HTML/CSS/JS достаточно обновить страницу; при необходимости — `Ctrl+F5`. Сервер отдаёт `Cache-Control: no-store`.

Прямое открытие `index.html` возможно, но само по себе не включает резервный движок: выбор зависит от наличия GSAP/ScrollTrigger, размера окна и настройки reduced motion.

## Утверждённые ограничения

Сохраняем белый внешний фон, голубой Hero, оранжевый акцент, плавающий хедер, фотографию и тексты «Сложные IT-проекты.» / «Доводим до запуска.». Расширяется фотография; тексты остаются на местах над ней. Переход должен обходиться без пружины, скачков, пустой паузы, копии заголовка и отрицательных компенсационных отступов.

Порядок аудиторий: малый и средний бизнес → Digital-агентства → веб-дизайн студии. Карточки исходно закрыты; раскрытие — по реальному движению указателя, с клавиатуры или по нажатию на touch. Размеры карточек пока не утверждены окончательно.

Не добавляем вымышленные кейсы, клиентов, отзывы, штат и метрики. Фото — концепт, не снимок команды. Текущий `mailto:` присутствует в исходниках, но публичный контакт требует согласования перед публикацией.

## Реализация и статус

В коде есть признаки v23.1: перемещается один оригинальный `.photo`, а пустой `.photo-position-holder` сохраняет место в сетке. Это подтверждено чтением JS/CSS; видимость фотографии и корректность анимации в браузере ещё не подтверждены.

GSAP и ScrollTrigger 3.12.5 подключены через `cdnjs.cloudflare.com`; локальных копий нет. При отсутствии библиотек предусмотрен native sticky. На ширине до 850 px, при соотношении сторон от 3:1 или reduced motion JS отключает закрепление. Активный режим необходимо проверять в браузере с учётом ограничений диагностики, описанных в [заметках](docs/v23-animation-notes.md).

Подтверждены HTTP 200 для страницы, CSS, JS и фотографии, наличие локальных ресурсов, один `h2#audience-title`, совпадение всех четырёх изображений с манифестом. Это не подтверждает рендеринг, доступность CDN, плавность прокрутки или работу карточек. Полная браузерная матрица остаётся открытой.
