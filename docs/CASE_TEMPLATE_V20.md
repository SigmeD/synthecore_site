## Зафиксированная композиция

1. Общий Header из partials и фирменный фон. Первый экран: H1, вводный текст и коллаж из трёх экранов. На телефоне остаётся главный экран согласно v20.
2. Одна двухколоночная история: «Наш процесс» → «Результат» → «Интерфейсы». Три этапа с кругами 32 × 32 px, вертикальной линией и плавной сменой активности.
3. Справа общий CTA «Готовы обсудить вашу задачу»: H3 32 px, текст 16 px, кнопка 52 px. На ширинах от 1100 px CSS sticky сопровождает все три секции и заканчивается перед «Другими работами». До 1099 px баннер идёт в обычном потоке после истории.
4. Результат с главным экраном без дополнительной монолитной рамки. Четыре превью интерфейсов, две колонки на desktop и одна на телефоне. Увеличение открывает `dialog`; Escape, фон и кнопка закрывают его, фокус возвращается к выбранному превью. Уголковых кнопок увеличения нет.
5. «Другие работы»: пять проектов из актуального каталога, текущий исключён по `catalog_id`. Применяются его реальные карточки, тексты, изображения и модалки. Desktop показывает три карточки, до 1180 px две, до 650 px одну. Стрелки неподвижны на hover; доступны клик и горизонтальный touch. Клоны для циклической прокрутки скрыты от доступности и Tab.
6. Общий Footer из partials. Параллакс ограничен кейсом; GSAP не закрепляет баннер или футер. `prefers-reduced-motion` отключает параллакс и переходы, делает шаги читаемыми и оставляет нативную прокрутку.

Не менять без отдельного поручения порядок секций, геометрию, sticky-границу, цвета, типографическую иерархию, фон и движение. Manrope остаётся общим шрифтом. Основные тексты — 16 px, служебные подписи могут быть 11–14 px. Общая политика кнопок без свечения включена в этот PR по дополнительному поручению владельца; она не меняет цвета, геометрию, outline или движение стрелок.

## Как добавить следующий кейс

Скопируйте только JSON данных в `templates/data/cases/<slug>.json`. Для изображений используйте `assets/cases/<slug>/`; общие CTA-иллюстрации находятся в `assets/cases/shared/`. HTML-копии и отдельный CSS/JS не создавайте: сборка сама выдаст `/raboty/<slug>/index.html`.

| Поля JSON | Правило заполнения |
|---|---|
| `slug`, `catalog_id` | URL и существующий ключ карточки. Beauty использует `beauty-insight` и `beauty`; остальные ключи перечислены ниже |
| `short_name`, `h1` | Краткое имя и строки H1; массив строк даёт контролируемый перенос |
| `status`, `intro` | Честный статус и конкретная задача. Статус также используется в доступном названии основной области |
| `meta_title`, `meta_description` | Фактические SEO-тексты без выдуманных обещаний |
| `process` | Объекты `title` / `body`. В эталоне три этапа. Другое число требует согласования содержания и проверки композиции |
| `result` | Что сделали и получили, без фиктивных KPI и эффекта внедрения |
| `hero_media.left/main/right`, `result_media` | `src` от `/assets/` и содержательный `alt` |
| `screens` | Ровно четыре объекта `src`, `alt`, `caption`; исходный файл используется также для увеличения |

Тексты экранируются; ввод произвольного HTML не поддерживается. Сборка отклоняет некорректный slug, пустые обязательные поля, отсутствующие изображения и небезопасные пути. Карточки других работ извлекаются из `templates/pages/works.html`, отдельный список проектов не ведётся. Каталожная дополнительная ссылка Beauty не копируется в карусель и не меняет её геометрию.

| Следующий проект / ключ каталога | Что подтвердить до наполнения |
|---|---|
| B2B-кабинет / `b2b` | Реализованный объём, этапы, итог и экраны |
| Заказ цветов / `flowers` | UX/UI-концепт и интерактивный прототип; фактические материалы |
| Кастомная CRM / `crm` | Реализованные функции и подтверждённый результат |
| «Простор» / `prostor` | Прототип интерфейса, дизайн-концепт; не действующий магазин |
| Расчёт металлоконструкций / `metal` | Реализованные расчёты и фактические материалы |

Пять новых страниц пока не созданы. Если материалов не хватает, перечислите недостающее и согласуйте упрощение до создания публичного кейса. Не подменяйте реальные экраны генерацией и не копируйте этапы Beauty как факты другого проекта. Все цифры интерфейсов Beauty демонстрационные, это не результаты внедрения.
