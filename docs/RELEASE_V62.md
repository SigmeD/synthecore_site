## Приёмка и дальнейшая работа

Подтверждены 75 статических тестов, 17 контрольных сумм анимаций, 25 файлов v27 и семь секций v62. Браузерная приёмка: 372 проверки движения, 295 проверок оболочки/каталога и повтор 139 проверок перед merge. Команды, доказательства и ограничения собраны в [QA](QA.md).

Сокращение документации не меняет код сайта. Полный архивный strict больше не описывает текущий набор документов; его исходный манифест сохраняется для истории.

Новые изменения выполняются через отдельный PR. Прежнее разрешение на PR #6 не разрешает автоматически сливать следующие PR или публиковать сайт. Если потребуется откат, его готовят отдельным PR с revert merge-коммита по первому родителю, без переписывания истории main.
