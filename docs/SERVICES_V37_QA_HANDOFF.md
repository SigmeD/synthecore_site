# SyntheCore — Services v37. Доработка состояний иконок

**База:** Services v36; изменения только в CSS блока услуг, актуализации теста и документации.

## Реализовано

- 6 карточек услуг; у каждой уже есть два самостоятельных SVG (mono/color) — файлы не перерисовывались и не изменялись.
- Неактивная иконка монохромная и наклонена: `rotateZ(-6deg) rotateY(-9deg) scale(.95)` с `perspective(850px)` и небольшим смещением вниз.
- При `hover` и `:focus-visible` обе позиции приводятся к `rotateZ(0deg) rotateY(0deg) scale(1)`; монохромная иконка уходит в opacity 0, оранжевая — в opacity 1.
- Анимация переключения: 380 мс прозрачность, 550 мс положение. Нет скачков: у SVG одинаковые атрибуты размеров и одна ячейка CSS grid.
- Карточка сохраняет фон Hero, подсветку тегов и небольшое поднятие.
- Отдельные обёртки изображений отсутствуют. Размер изображений остаётся 85% от предыдущего слота (−15%).
- На устройствах без hover доступно короткое состояние через `:active`. `prefers-reduced-motion` отключает перемещения и переходы.

## Не меняли

`index.html`, `js/services.js`, `js/main.js`, скрипты Hero, `js/works.js`, `css/main.css`, `css/works.css`, содержимое всех SVG и изображений. Скролл и pin используются прежние; второй Lenis не создаётся.

## Проверки

- Статические тесты `verify-services-static.cjs`, `verify-works-static.cjs`, `check-project.cjs`: PASS.
- Автономный HTML в Chromium на 1440×900, 390×844, 320×700 и 1440×900 с `prefers-reduced-motion: reduce`: JS page errors 0, горизонтального переполнения документа нет.
- 1440×900: initial mono opacity 1 / color 0, при hover mono 0 / color 1. CSS matrix3d исходного наклона отличается от итоговой выровненной матрицы; фоновый gradient активен.
- Вертикальный скролл двигает pinned track вперёд и обратно. Проверено изменение счётчика `01 — 06 → 03 — 06 → 01 — 06`.
- Реальные мобильные устройства, Safari и интеграция на production не проверялись. В браузерном тесте HTML открывался автономно со встроенными ресурсами, не через HTTP.

## Риски и контроль

- Наклон выполнен CSS-трансформацией целой иллюстрации. В отличие от возможного 3D-рендера с изменением ракурса это не меняет перспективу деталей внутри SVG; не следует утверждать, что 3D-позы полностью совпадают с Roveia.
- На сенсорных устройствах постоянного hover нет; для поведения используется `:active`, основная горизонтальная навигация сохранена.
- После переноса в Git требуется пройти браузерную регрессию на сервере и визуально сравнить переход Works → Services.

## Передача

Для интеграции достаточно изменить `css/services.css` и обновить тест. Не заменять целиком содержимое основного Git-репозитория архивом.
