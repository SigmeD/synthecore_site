# SyntheCore — Services v33: проверка и передача

Дата: 15.10.2026. Основа: `synthecore(1).zip` с предварительным прототипом v32.

## Что реализовано

- Секция `#services` находится непосредственно после `#works`.
- Контент и все шесть карточек услуг сохранены.
- Габариты карточки: 500×500 CSS px на 1920×1080; около 403×459 на 1440×900.
- Стиль `Что мы делаем` соответствует фактическим значениям заголовка `С кем работаем`: 32px, font-weight 400, line-height 1.2, letter-spacing -.055em.
- Переход после шестой работы: подъём и параллакс новой секции, пока последняя карточка естественно уходит вверх.
- Вся секция закрепляется через `GSAP ScrollTrigger` на desktop (>850 px, высота ≥650 px, без reduced motion).
- Вертикальный скролл переводится в горизонтальный `transform` карточек. Колесо, touch и Lenis не перехватываются.
- По завершении горизонтального перемещения ScrollTrigger снимает закрепление, идёт блок контактов.
- На планшете/телефоне: обычная горизонтальная прокрутка, свайпы и стрелки; при `prefers-reduced-motion` нет принудительного закрепления.
- Отступ между Works/Services сокращён **отрицательным margin только новой секции**; исходная галерея Works и её последний hold 85svh оставлены без изменений.
- Все общие стили и скрипты Hero/Audiences/Works сохранены.

## QA / Адверсальная проверка

Проверено в Chromium с автономной HTML-страницей (все библиотеки, стили и изображения встроены внутрь, так как файловые URL в проверочной среде блокируются).

| Среда | Режим | Результат |
|---|---|---|
| 1920 × 1080 | pinned | карточки 500×500; вертикальный скролл движет ряд по горизонтали |
| 1440 × 900 | pinned | карточки ~403×459; заголовок фиксирован |
| 768 × 1024 | native | горизонтальная прокрутка; без переполнения страницы |
| 390 × 844 | native | свайп; без переполнения страницы |
| 320 × 700 | native | свайп; без переполнения страницы |
| 1440 × 900, reduced motion | native | закрепление отключено |
| 390 × 844, reduced motion | native | закрепление отключено |

Существующих работ по-прежнему шесть. Проверены вход/выход из закрепления и обратная прокрутка при pinned-режиме. Ошибок JavaScript в этих сценариях нет. Проверены ширины, текстовые зоны карточек (не переполняют контейнер) и уникальность ссылочных ID.

**Риски и ограничения:**
1. До окончательной приёмки нужно проверить скролл на реальном устройстве/сервере вместе с Lenis в Safari и на телефоне.
2. `loading=lazy` у дальних изображений: они намеренно догружаются при приближении к зоне просмотра.
3. При viewport менее 851px применяется нативный горизонтальный скролл для корректных touch-жестов, а не закрепление всей страницы.
4. Отрицательный отступ `-75svh` (desktop) / `-55svh` (mobile) согласует уход Works и вход Services. При будущих изменениях `--works-step`, `--works-aspect` или `--works-last-hold` отступ перепроверить.
5. Это воспроизведение логики движения по пользовательским DevTools-скриншотам; исходные обработчики анимаций сайта Roveia не копировались.

## Приёмка
Сверить при прокрутке вниз/вверх:
- шестая работа полностью покидает экран без принудительного обрыва;
- заголовок появляется, занимает верхнюю среднюю часть секции и не смещается во время горизонтального движения;
- видны первая и последняя карточки, без горизонтального переполнения страницы;
- после последней карточки доступен `#contact`;
- якоря навигации `#works`, `#services` и `#contact` работают;
- мобильный горизонтальный свайп не перехватывает вертикальное движение;
- режим уменьшенной анимации читабелен и управляем.
