# SyntheCore Services v35 — иконки

- Созданы шесть новых самостоятельных SVG-иллюстраций с прозрачным фоном; это не CSS-перекрашивание v34.
- Сюжеты: веб-сервис, автоматизация, API, аудит, серверы/запуск, AI.
- Палитра: фирменный оранжевый, белые керамические поверхности, мягкие объёмные градиенты.
- Иконки SVG, их можно использовать в CSS-карточках без растровой подложки.
- Hover карточки: градиент Hero и лёгкое поднятие; иконка мягко увеличивается, без смены исходной палитры.
- Разметка, шесть работ и JS скролла не менялись.
- Для сверки оригинальной 3D-стилистики с референсными WebP требуется финальное визуальное согласование.
