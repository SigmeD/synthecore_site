# SyntheCore v45 — Works → Services, контрольная передача

Дата: 16.10.2026. База: **v43** (v44 отклонена). Параллельные изменения Git не выполнялись.

## Цель

Сохранить появление каждой карточки снизу окна и устранить задержку/белый хвост после шестой работы без изменения Hero, аудиторий, работ, иконок и горизонтального скролла услуг.

## Подтверждённая причина v44

`y: innerHeight` у входящих карточек рассчитывался от высоты окна, но уменьшенная сцена Works имела `overflow: hidden`. Поэтому видимость следующего кадра начиналась у границы укороченной сцены, а не снизу экрана.

## Изменения v45

1. `css/works.css`: высота закреплённой сцены равна `var(--works-height) + 2 * var(--works-padding)` — фактической высоте карточки с внутренними полями; `.sc-works-stack` в анимированном режиме имеет **`overflow: visible`**. Положение изображения и оформление не менялись.
2. `js/works.js`: вход сохраняет `y: innerHeight`; удалён `LAST_HOLD` и связанная с ним пауза; `scrub:true` без дополнительного сглаживания поверх Lenis. Одна GSAP Timeline для шести работ, один ScrollTrigger.
3. `js/services.js`: начальный сдвиг секции для лёгкого параллакса уменьшен до `min(35px, 4.5vh)`, исчезновение прозрачности отключено; pin и горизонтальный скролл Services не изменены.
4. Отрицательные межсекционные margin, отдельные spacer-элементы и wheel-перехваты не добавлялись.

## Проверка

Автоматизированный браузерный прогон на автономном HTML, с заменой изображений на облегчённые тестовые заполнители (сохраняются DOM, стили, JS и размеры изображений):

| Размер | Результат |

| 1440 × 900 | PASS |
| 1920 × 1080 | PASS |
| 768 × 1024 | PASS |
| 390 × 844 | PASS |
| 320 × 700 | PASS |

Проверены: начальное положение шестой работы ниже видимой части окна, вход поверх пятой, совпадение нижней границы Works и верхней границы Services после pin, обратная прокрутка, отсутствие ошибок JS и горизонтального переполнения страницы. Геометрический зазор секций при выходе Works: **не более 0,4 px** в проверенных браузерных измерениях. Визуальные контрольные кадры для последних двух работ снимались с их исходными изображениями; остальные изображения в этой отдельной QA-сборке заменены заполнителями для ускорения.

Статические проверки:

## Риски и ручная приёмка

- Проверка с реальным колесом и на физических телефонах остаётся за владельцем сайта.
- Плавность может отличаться на устройствах, где Lenis или особенности браузерного скролла работают иначе.
- `overflow: visible` намеренно позволяет ещё не показанным карточкам находиться ниже сценического контейнера. Если появятся побочные эффекты перекрытия с другими секциями, нельзя снова включать `overflow: hidden`, не переработав одновременно начальные координаты входа.
- Визуальная близость Roveia оценивается по присланным видео и скриншотам, а не доказана копированием исходной анимации сайта.
