# SyntheCore v60 — меню, CTA и волны футера

**База:** v59, без переноса каких-либо файлов из иных проектов.

## Изменения
- Навигация (desktop, mobile, footer): «Работы → Услуги», затем остальные пункты по месту. Порядок самих секций сайта не менялся; все ссылки сохраняют прежние цели.
- Шапка: чёрная CTA-кнопка «Обсудить задачу» плавно меняет фон на фирменный `#E44D1F` при наведении/фокусе; без вертикального сдвига.
- Оранжевая CTA (hero и footer): исходный `#E44D1F` при наведении становится светлее `#FC7045`. Без подпрыгивания самой кнопки.
- SVG-стрелки CTA поворачиваются на −45° вокруг центра при hover/focus/active — как стрелки FAQ при раскрытии. Перенос/подпрыгивание иконок убраны. Мобильная кнопка меню тоже получила SVG вместо символа.
- Футер: высота SVG-волн на desktop увеличена с 410 до 490 px, mobile — с 325 до 390 px; амплитуда изменения формы немного увеличена, фильтр размытия снижен; слои независимо движутся 15–24 секунд, даже без прокрутки.
- При `prefers-reduced-motion` движение волн и CTA-стрелок отключено.

## Изоляция
Изменены только `index.html`, `css/main.css`, `css/faq-footer.css`. Старые CSS/JS модулей hero, services, works, testimonials, process, FAQ-logic не изменялись. Секция FAQ и её правила раскрытия сохранены.
