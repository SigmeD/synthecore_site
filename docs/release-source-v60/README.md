# SyntheCore — v43 (16.10.2026) · единая анимация Works

**Актуальная основа:** v41. Новый блок Works реализован одной закреплённой GSAP Timeline вместо отдельных sticky-карточек. Все шесть работ, их изображения, подписи и визуальная геометрия сохранены. Никаких дополнительных элементов-spacer между карточками нет; `pin-spacer` создаёт сама GSAP. Services по-прежнему использует собственный независимый ScrollTrigger и горизонтальную прокрутку.

- `js/works.js`: один ScrollTrigger `sc-works-timeline`, пять последовательных входов карточек, финальная короткая фиксированная фаза и освобождение сцены; прогресс обновляется одинаково при движении вниз/вверх.
- `css/works.css`: одна сцена высотой в экран, кадры наложены с вычисляемым z-index; без JS/reduced motion — обычный вертикальный список.
- `js/services.js`: только `refreshPriority:-15` у входной анимации, чтобы сначала измерялись Hero → Works → Services. Само поведение услуг не менялось.
- Без внешних теней Works. Тени внутренних текстовых панелей сохранены.
- Перед Git-интеграцией сравнить текущую ветку с данной версией; переносить выборочно, не заменять весь репозиторий.

Отчёт о реализации, ограничениях и браузерных проверках: [WORKS_TIMELINE_V43.md](../WORKS_TIMELINE_V43.md).

# Обновление v41 — исправление положения шестой работы (16.10.2026)

## Локальный запуск

В PowerShell из папки проекта:

```powershell
.\start-local.ps1
```

Или запустите `start-local.bat`. Сервер открывает [локальную страницу](http://127.0.0.1:4173/), отдаёт файлы без кеширования и останавливается через Ctrl+C. Другой порт: `.\start-local.ps1 -Port 4174`. Если сервер уже работает, достаточно обновить страницу.

Для сайта не нужны установка пакетов, Node, Python или сборка: HTML, CSS, JavaScript, изображения и библиотеки находятся в репозитории. Node нужен только для проверок, Playwright и Chromium — для браузерной приёмки.

## Проверки

Из корня репозитория:

```powershell
node scripts/check-project.cjs
node scripts/verify-works-static.cjs
node scripts/verify-services-static.cjs
node scripts/check-hero-geometry.cjs
node scripts/test-static-checks.cjs
git ls-files --cached --others --exclude-standard | node scripts/check-doc-links.cjs
```

Это базовые проверки структуры v31 + новый тест услуг v32. Они проверяют структуру, ресурсы и геометрию без сервера. При работающем сервере `node scripts/check-project.cjs --http http://127.0.0.1:4173/` дополнительно сравнивает отданные ресурсы с файлами. Визуальное поведение проверяется отдельно по [QA v31](../QA_V31.md). Браузерный сценарий сохраняет сравнимые состояния:

```powershell
node scripts/verify-v31-browser.cjs --capture=before
node scripts/verify-v31-browser.cjs --capture=after
```

Для другого адреса задайте `$env:SYNTHECORE_URL = 'http://127.0.0.1:4174/'`. Подключение к отдельному Chromium описано в [инструкции доступа](../chromium-access.md). Команды выше не являются заявлением об успешном запуске; результаты и ограничения фиксируются в QA. Старые `verify-hero-gate*` и отчёты v23 относятся к прежним итерациям; их назначение — в [реестре исторических сценариев](../../scripts/HISTORICAL_CHECKS.md).

## Устройство сайта

`index.html` подключает `css/main.css`, локальный CSS Lenis, `css/works.css` и `css/services.css`; затем defer-скрипты GSAP/ScrollTrigger 3.12.5, Lenis 1.3.26 и пять скриптов сайта. Единственный владелец Lenis — `js/hero-scroll.js`. Works использует CSS sticky и по одному GSAP tween на карточку; свою прокрутку не создаёт. Композиция Works и существующие анимационные алгоритмы сохраняются при рефакторинге.
