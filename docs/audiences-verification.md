# «С кем работаем» — доработка и проверка

14 октября 2026 г. Изменён только блок #audiences. База — текущая локальная версия с работающим Lenis Hero. Новый номер версии не назначался. Chrome 149.0.7827.55 через CDP 127.0.0.1:9222.

## Результат

- Заголовок 32px, line-height38.4px, отступ после него36px на всех проверенных размерах.
- Общий контейнер 1200px; на desktop две настоящие колонки, список слева, preview справа. Карточка больше не вынесена за правую границу контейнера.
- Крупные названия сохранились, вес 380→300. Текст карточки 16px/24px, вес 400.
- Карточка определяется содержимым, а не абсолютным flex внутри фиксированной высоты. Три статьи занимают одну ячейку grid; высота учитывает самую длинную и не меняется при переключении.
- Иллюстрации уменьшены примерно на 15–20%, object-fit contain, flex shrink исключён; все три картинки полностью внутри карточки.
- Три span «Смотреть ↗» удалены. Существующие кнопки занимают всю строку и сохраняют hover, touch, клавиатуру, aria-pressed и inert/aria-hidden статей.
- Теги без рамок/padding, в одну строку. Контент, порядок, оранжевые акценты, изображения и анимации сохранены.
- Нижний отступ секции 80–112px. Более специфичный старый shorthand перекрывал новую настройку; это исправлено после независимого review.

## Сравнение одинаковых viewport

[До 1920×1080](../output/playwright/audiences/before-1920x1080-0.png), [после 1920×1080](../output/playwright/audiences/after-1920x1080-0.png), [Roveia 1920×1080](../output/playwright/audiences/roveia-1920x1080-0.png).

Live [Roveia](https://www.roveia.com/) открыт в том же Chromium и том же 1920×1080. Сняты закрытый блок и все три hover-карточки. Измерены заголовок 32px/38.4px, контейнер 1200px, padding карточки 24px, текст 16px/24px. Габариты hover-карточек с учётом их поворота — примерно385×513,369×498,369×501px. Их иллюстрации имеют заданную ширину 165px. SyntheCore сохраняет собственные тексты и изображения, а уменьшение иллюстраций выполнено относительно SyntheCore, как задано пользователем.

В текущем live Roveia между заголовком и списком flex-gap 80px; это отличается от ориентира 32px в задании. Для SyntheCore приоритет имеет требование пользователя 32–40px, поэтому выбран 36px. Live-параметры и HTML записаны в before-metrics.json; совпадение со старыми скриншотами не предполагается.

При 1920×1080 прежний локальный heading был 38.4px, при 4K — 42px. Это уточнение измерений при одинаковом окне, а не изменение заданных целей.

## Проверки

[acceptance.json](../output/playwright/audiences/acceptance.json) — семь viewport passed, ошибок JavaScript нет: 1366×768,1920×1080,3840×2160,390×844,430×932,850×900,851×900.

Для каждого размера проверены все три категории: правильная active/aria/inert, изображение декодировано и целиком внутри статьи, содержимое помещается, теги в одной строке без рамок, отсутствует горизонтальная прокрутка. Desktop: две колонки, границы общего контейнера, текст в своей колонке, одинаковая высота карточки при переключении. Проверены Enter, Space, ArrowDown, Escape, hover/leave и reduced motion. Mobile: переключение и повторный tap закрывают preview, закрытая карточка не резервирует пустую область.

Независимый review подтвердил читаемость, отсутствие crop и сохранность сетки на 1920/1366/4K/mobile. Отдельные независимые browser cases 851×900 и390×844 прошли все три категории, hover/tap/клавиатуру и отсутствие ошибок. Существенных оставшихся дефектов не найдено.

Сохранность соседей проверена по backup: index.html отличается только удалением трёх согласованных span; js/main.js побайтово прежний; исходный CSS сохранён целиком, все добавления ограничены #audiences. Hero-контроллеры не редактировались. Общая проверка проекта прошла: 11 хешей ассетов/библиотек,12 HTTP-ресурсов совпали с диском; расчётные 60 crop-состояний Hero прошли. Перемещение следующих секций вверх является следствием более компактного блока, их содержимое/стили не менялись.

Проверки относятся к Chromium с эмуляцией размеров/touch; реальные телефоны и другие браузеры не проверялись.
