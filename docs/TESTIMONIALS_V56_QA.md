# SyntheCore v56 — отзывы, последовательная анимация

**Основа:** v55. **Статус:** кандидат на визуальное согласование и локальную приёмку; не опубликован.

## Что изменилось

- Четыре демонстрационные карточки движутся при вертикальной прокрутке **справа налево через центр заголовка**, с частичным перекрытием по времени и мягким изменением масштаба/наклона. Карточки больше не размещены по четырём углам.
- Заголовок «Что говорят клиенты» на desktop находится по центру во время сцены. Вход при переходе из «3 шага до запуска» сглажен; предыдущий баннер мягко уменьшается и приподнимается.
- Стандартный `position: sticky`, **без нового GSAP `pin`**. Четыре карточки проходят через одну управляемую шкалу прокрутки; нет захвата колеса мыши или собственной прокрутки страницы.
- При наведении карточка увеличивается в 1.06 раза, CSS-анимация парения временно прекращается; после ухода курсора возвращается. Названия карточек и шрифты сохранены.
- В конце секции карточки мягко исчезают. При прокрутке назад движение происходит в обратном направлении.
- Карточки почти белые с едва заметными прежними голубым, персиковым, лавандовым и мятным градиентами. Состав, тексты и портреты-заглушки сохранены.
- На ширине менее 1200 px или высоте менее 800 px — нативная горизонтальная лента, без sticky-сцены. При `prefers-reduced-motion: reduce` — без анимации карточек.
