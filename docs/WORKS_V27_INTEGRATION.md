## Интеграционные исправления

- Пути логотипа/навигации работают с обоих URL; Header «Работы» ведёт на каталог, существующая секция `#works` на главной остаётся.
- У PNG исправлены ошибочные HTML width/height 1200×600 на фактические размеры исходников; CSS-геометрия сохранена.
- Удалено наследуемое перемещение стрелки карточки из старого base CSS; v27 hover оставляет стрелку неподвижной.
- Диалоги приостанавливают Lenis, блокируют документ и восстанавливают фокус/scroll после закрытия.
- Плавный переход к Contacts на Works переносит клавиатурный фокус к целевой секции, как на главной. Проблема подтверждена тестом до исправления.
- Волны защищены от двойного запуска, останавливаются вне viewport и при reduced motion; оригинальный алгоритм и параметры сохранены.
- Исправлен унаследованный из архива дефект: copyright на 390×844 оставался прозрачным в конце документа. Только для `.sc-footer__fine` используется наблюдение без отрицательного rootMargin; CTA и нижняя навигация сохраняют исходный порог −7%, длительности/easing всех элементов сохранены. Сбой подтверждён на архиве и интеграции до исправления.
- `start-local.ps1` обслуживает directory index `/raboty/` и font MIME types. `-NoBrowser` позволяет проверять сервер без открытия окна.

## Запуск и изменение

```powershell
node scripts/build-site.cjs
.\start-local.ps1
```

Открыть `/` и `/raboty/` на `http://127.0.0.1:4173/`. На существующем статическом хостинге достаточно готовых HTML/CSS/JS/assets, установка зависимостей и runtime-сборка для сайта не нужны. При изменении partial/шаблона снова выполнить build и включить готовые HTML в коммит.

Проверки и результаты: [QA](qa/works-v27/README.md). Используемые инструкции библиотек сверены через Context7 с официальным README Lenis; новые опции из свежих версий не добавлены в локальную 1.3.26. Версии библиотек не обновлялись.
