Сравнение охватывает `/`, `/raboty/`, Beauty, Flowers и Metal на **320, 390, 768, 1440 и 1920 px**. Для всех сравниваются развёрнутый порядок CSSOM, декларации, контексты групп, URL, видимые computed styles, фактическая геометрия, отсутствие overflow. Для главной дополнительно требуется **ноль отличающихся пикселей** первого экрана на всех пяти ширинах. [Desktop](home-1440.jpg) и [Mobile](home-390.jpg) — компактные снимки текущей главной.

HTML четырёх неизменных маршрутов сравнивается после нормализации окончаний строк LF/CRLF: `git archive` и рабочее дерево имеют разные окончания. Их CSSOM и геометрия совпали. Вычисленные used values автоматических margins нестабильны при layout flush, поэтому margins проверяются декларациями CSSOM и фактическим расположением, а не transient-значениями `getComputedStyle`.

Пиксельные отличия остальных маршрутов сохранены в отчёте как диагностика. Они возникают и при повторной загрузке **одного и того же URL**: [контрольный опыт](same-url-control.json). Эти страницы не объявляются пиксельно идентичными. Первоначальные отказы сравнительного сценария из-за LF/CRLF, transient margins и raster noise исправлены на уровне измерений; runtime ради прохождения QA не менялся.

Проверены обычная/обратная прокрутка главной и секции до футера, единственный прежний владелец движения, мобильное меню и переход в `prefers-reduced-motion`. Полные проверки кейсов и основных действий повторены после извлечения общих browser helpers. Независимое code review проверило сборщик, точные исключения, отрицательные тесты и достоверность сравнительного отчёта; замечаний P1/P2 не осталось.

Ограничения: Chromium automation, без Firefox/WebKit и физических мобильных устройств. Автоматический wheel не доказывает субъективную плавность мышью/тачпадом. Главная сравнена пиксельно только в первом viewport; нижние секции покрыты CSSOM, проверками исходников и сценариями прокрутки. Performance benchmark не проводился.

`git diff --cached --check -- . ':!css/generated/home.css'` проходит. Собранный CSS сохраняет пробелы и пустые строки исходников: общий `--check` показывает унаследованные trailing whitespace только в этом артефакте. Его корректность проверяется точной пересборкой, исходные файлы ради форматирования не менялись.

Воспроизведение статической приёмки: `node scripts/verify-site.cjs --git-ref HEAD --http http://127.0.0.1:4176/`. Для сравнения нужен отдельно запущенный базовый экспорт; затем `node scripts/verify-css-refactor-browser.cjs`. Адреса настраиваются через `SYNTHECORE_URL` / `REFACTOR_BASELINE_URL`. Эталоны и Playwright не включены в репозиторий. Временный экспорт этой задачи после проверки удаляется; исходный коммит остаётся в Git.
