# Get Started v4.9.2

Интеграция от 26 октября 2026 года поверх `origin/main` `6575dd78049108df3b4f5b70894651a45b075813`. Ветка `feature/get-started-v4-9`; результат предназначен для PR, без слияния и публикации.

`/get-started/` и `/privacy/` генерируются из двух шаблонов с существующими Header/Footer. Шесть карточек, их тексты, обе метки, изображения и адреса поступают из актуального каталога и зарегистрированных JSON-кейсов. Карусель использует transform/transition из v4.5+, без возврата к scroll-snap. Прежние владельцы меню, Lenis и футера сохраняются.

Изменения прежних страниц — только восемь `href` в пяти исходных HTML и соответствующая пересборка: desktop/mobile Header, Footer, Hero главной, вступление/скрытая модалка каталога и контентная/модальная кнопки шаблона кейса. Остальные ссылки не заменялись. На форме локальные CTA ведут к `#request` без перезагрузки, на privacy — `/get-started/#request`. Строгое обратное преобразование зарегистрированных ссылок позволяет проверять прежние SHA без изменения manifests.

## Проверка

Уточнение по логотипу от 26.10.2026: исходные page-specific CSS задавали Manrope всему `body`, из-за чего неизменённый хедер наследовал другой шрифт. Теперь Manrope ограничен `main`, а логотип наследует стек Inter/системного шрифта общей оболочки. [Новая проверка 182/182 PASS](shell-report.json) сравнивает font-family, weight, size, tracking, line-height и размеры шести элементов хедера/футера с каталогом на 320/390/768/1024/1440/2560 px в обоих режимах движения; отдельно подтверждает Manrope содержимого и прежнюю геометрию формы относительно эталона. Скриншоты ниже обновлены после этого исправления.

Базовая браузерная приёмка коммита `4df584b` до уточнения шрифта: **410/410 PASS**, **52 активации CTA**, 24 загрузки двух маршрутов на 320/390/768/1024/1440/2560 px в normal/reduced motion, 12 сравнений геометрии с эталоном на 390/1440 px. Эта приёмка не проверяла наследование шрифта логотипа; его покрывает новый отдельный отчёт выше. Ошибок JavaScript, HTTP и загрузки ресурсов нет. ## Ограничения перед публикацией

Форма только проверяет поля и готовит письмо с международным телефоном. Пользователь должен открыть и отправить письмо вручную. Серверного приёма, сохранения лида и CRM-интеграции нет; введённые данные не очищаются. Маска проверяет количество цифр, но не существование номера. Backend и проверка телефона на сервере — отдельное поручение.

`/privacy/` — черновик v1.0: нужно подтвердить юридическое наименование оператора, сроки хранения, обработчиков и канал приёма обращений. Это блокер публикации, а не выполненная юридическая проверка. Merge и публикация не разрешены текущим заданием.
