## Карта переноса и факты

Общий каркас v20 получил два утверждённых partial-варианта: композицию из трёх смартфонов и два устройства результата. Default Beauty сохранён побайтно после отмены единственной новой ссылки Flowers в «Других работах». Прочие пять карточек каталога сохранены полностью. Главная, каталог и готовый кейс получают маршрут Flowers из JSON через действующий реестр.

Перенесены только `detail-flowers.css` с локальной областью `body.sc-case-flowers` и префиксом keyframes, четыре WebP и фактические тексты в JSON. Все четырнадцать общих CSS/JS комплекта совпадают с принятой v20 по SHA; действующие Header/Footer, библиотеки, Manrope, общий CSS/JS и CTA-ассеты переиспользуются. Специфический CSS и все четыре изображения предоставленного HTML-превью совпали с ZIP. Архив, standalone preview, исходные дубликаты vendor и посторонние Beauty-ассеты не добавлены.

Заголовок, вводный текст и обе метки намеренно берутся из `/raboty/` по глобальному правилу. Поэтому формулировки первого экрана отличаются от самостоятельной v2, сохраняя согласованную композицию. Статус — UX/UI-концепт и интерактивный прототип. PWA, выпущенное MVP, Android/iOS-релиз, продажи, конверсия и экономический эффект не заявляются. 80% покупок со смартфонов явно приписаны данным заказчика на этапе анализа, без представления как результата нашей работы.

В исходном `main` на момент ответвления есть только Beauty. Metal остаётся в отдельном PR #12 и в эту ветку не импортирован; у него и трёх остальных работ действует прежняя модалка, без несуществующих ссылок. Это отдельный PR к `main`, без зависимости от разрешения на слияние Metal.
