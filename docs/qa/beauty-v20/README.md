Сравнение эталона проверяет выбранные размеры и шрифты, а не полную пиксельную идентичность. В «Других работах» используются актуальные тексты каталога вместо старых названий из ZIP. Поэтому высота карточки с длинным текстом на 320 px может отличаться от ZIP по обычному min-content; исходный компонент каталога, ширина, пропорция, теги и поведение сохранены. Типографика CTA восстановлена локальным fallback 32 px без изменения глобальных токенов. В главной и каталоге отличаются только согласованные входящие ссылки и включённая политика свечения.

Независимое code review выявило и помогло исправить копирование дополнительной ссылки в будущие карусели, возможность неправильного размещения ссылки при SHA-нормализации и интерпретацию фигурных маркеров из текста как partials. Эти сценарии закреплены тестами.

Все скриншоты и записи в этой папке получены заново на интеграции. Снимки из ZIP не используются как доказательство её работоспособности.

Ограничения: ручная плавность физической мышью/тачпадом, реальные мобильные устройства, Firefox/WebKit и production не проверяются автоматическими сценариями. Цифры на экранах Beauty демонстрационные; эффект внедрения не заявляется. Будущие пять страниц не создавались. Merge и публикация не выполняются.
