## Что изменено

Данные `prostor.json`, два partial hero/result, изолированный `case-prostor.css`, 14 используемых изображений (4 686 524 байта: семь WebP и семь PNG) и готовый HTML. Минимальное расширение генератора разрешает ровно семь разных `screens` только варианту `prostor-v1` с его собственными slug/catalog_id; `full_src` проверяется как локальный существующий asset и используется прежним lightbox. Четыре этапа и их тексты перенесены из v1 без изменения смысла. Семь экранов: магазин, категории, каталог и фильтры, корзина, кабинет покупателя, CRM менеджера, кабинет владельца.

Главная и каталог получили прямой anchor через существующий реестр. В Beauty, Flowers и Metal изменился только anchor Prostor в «Других работах». Их полный HTML после отмены этого единственного добавления сравнивается с новой базой по SHA. Общий шаблон, Header/Footer, runtime CSS/JS, vendor и исходные manifests сохранены. Сам исходный ZIP, автономный HTML и QA-экспорты остаются в ignored `output/`.

Остальная композиция, карточки, общие компоненты и движение берутся из действующего сайта.

Ограничения: проверялся Chromium с эмуляцией размеров и touch. Firefox/WebKit и физические устройства не проверялись. Автоматические wheel/touch не подтверждают субъективную плавность на физической мыши или тачпаде. Пиксельная идентичность всех страниц не заявляется.

Независимое read-only code review проверило минимальность генератора, отрицательные тесты, соответствие контента v1, SHA изображений и отсутствие изменений в замороженных областях. Обязательных исправлений не обнаружено. Результаты браузера и полной suite получены основным агентом, а не заменены заключением review.

## Как повторить

Текущий сайт — `http://127.0.0.1:4176/`, распакованный v1 — 4194, экспорт базового main — 4195. В исходном ZIP нет fonts, поэтому сервер сравнения использует существующие `/assets/fonts/` проекта; исходники самого v1 не менялись. Можно указать свои адреса через `SYNTHECORE_URL`, `PROSTOR_REFERENCE_URL`, `PROSTOR_BASELINE_URL`. Нужна существующая локальная установка Playwright; эталоны и браузер в Git не входят.

```powershell
node scripts/build-site.cjs --check
node --test scripts/test-prostor-case.cjs
node scripts/verify-prostor-browser.cjs
$env:CASE_PROJECT = 'prostor'
node scripts/verify-case-links-browser.cjs
node scripts/verify-site.cjs --git-ref HEAD --http http://127.0.0.1:4176/
```

Полный перечень изменённых файлов: [changed-files.txt](changed-files.txt). Старые отчёты других интеграций не заменяют эти результаты.
