# CRM v1 — приёмка интеграции 25.10.2026

Основа: `origin/main` `f710d44b1926629961816c807e255854585ab7e4` после согласованного merge B2B PR #16. Ветка `feature/crm-case-detail`, маршрут `/raboty/crm/`. CRM подготовлена для отдельного PR; merge и публикация не выполнялись.

Источники: `SyntheCore_CRM_Agent_Kit_v1.zip`, внешний MD и отдельный `SyntheCore_CRM_Detail_v1_preview.html`. Kit содержит шесть экранов, copy и README/QA, но не отдельный index/CSS. В генератор перенесены только данные, изображения и локальный style-блок CRM из превью. [Source audit](source-audit.json) фиксирует SHA входных файлов, шести изображений и 80 исходных Git blobs. Четыре этапа и результат дословно совпали с `case_copy.md`; все три WebP и три PNG — со встроенными данными превью. Автономный HTML, vendor, fonts и другие ассеты в production не копируются.

## Перечень изменений

- `templates/data/cases/crm.json`, два partial hero/result и сгенерированная `raboty/crm/index.html`.
- Шесть исходных изображений в `assets/cases/crm/`: 6 387 697 байт, PNG 1448 × 1086 и оптимизированные WebP. Сделка / компании / аналитика не дублируются и не перегенерированы.
- `css/case-crm.css` — только утверждённый CRM style-блок со сменой scope на `body.sc-case-crm`.
- Минимальный `crm-v1` в существующем renderer: привязка к собственным slug/catalog_id, строго четыре этапа и три уникальных интерфейса, безопасный `full_src`. Прежние counts/варианты сохраняются.
- Главная, каталог и пять старых кейсов получают только зарегистрированный anchor CRM. Все шесть работ ведут на детальные страницы; модальные JS/узлы сохранены.
- Тесты CRM и отдельная браузерная приёмка. У старого B2B-теста обновлены только ожидание готовой CRM-ссылки и набор точных поздних anchors после своего baseline-реестра. Его исходный audit/SHA, общий строгий helper и отрицательные проверки сохранены.
- Актуальные инструкции и этот отдельный QA-отчёт. [Полный список файлов](changed-files.txt).

Название **«CRM для управления продажами»**, описание, SEO и обе метки «Веб-сервис» / «Клиенты и сделки» берутся из каталога. Рабочее «Кастомная CRM» не становится независимым H1. Подтверждённый текст описывает собственную CRM; production-запуск, внедрение у заказчика, количество клиентов, рост продаж и измеренные показатели не заявляются. Цифры и контакты скриншотов демонстрационные; проверка перед публикацией остаётся отдельным шагом, публикация здесь не выполнялась.

Композиция: компании слева, сделка по центру, аналитика справа. Результат — аналитика. Галерея: «Карточка сделки» → «Компании и контакты» → «Аналитика продаж». Никакого четвёртого изображения для симметрии. Общий template, runtime CSS/JS, Header/Footer, библиотеки, 17 motion-файлов и manifests не меняются. Семь старых полных HTML сравниваются с Git-базой после отмены только CRM anchor.

Новая база хранит Git blob SHA отдельно от исходных Windows working SHA: только 18 явно перечисленных non-motion текстов учитывают LF/CRLF. Ни один защищённый motion-файл не нормализуется. Сохранённые отчёты исходного ZIP не подменяют эту приёмку.

## Отличия и ограничения

H1/intro/SEO берутся из каталога по заданию. Заголовок длиннее «Кастомная CRM» из превью; переносы и вертикальное положение следующих разделов поэтому отличаются. Три экрана и их пропорции/рамки, результат, последняя строка галереи и CTA используют согласованные размеры. Действующие Header/Footer, общая политика кнопок и живые карточки заменяют автономные копии окружения.

Проверялся Chromium с эмуляцией размеров и touch. Firefox/WebKit, реальные устройства и субъективная плавность физической мышью/тачпадом не проверялись. Пиксельная идентичность всех страниц не заявляется. Исходные лица, контакты и интерфейсы не изменялись и не генерировались.

## Как повторить

Нужна существующая локальная установка Playwright. Node QA HTTP 4198 отдаёт те же файлы проекта, что локалка 4176; предоставленное CRM-превью — 4199, экспорт `f710d44` — 4200. Локальные Manrope для превью доступны из действующего проекта; исходный HTML не менялся. Экспорты/серверы и браузер в Git не входят. Адреса задаются через `SYNTHECORE_URL`, `CRM_REFERENCE_URL`, `CRM_BASELINE_URL`.

```powershell
node scripts/build-site.cjs --check
node --test scripts/test-crm-case.cjs scripts/test-b2b-case.cjs scripts/test-prostor-case.cjs
$env:SYNTHECORE_URL = 'http://127.0.0.1:4198/'
node scripts/verify-crm-browser.cjs
$env:CASE_PROJECT = 'crm'
node scripts/verify-case-links-browser.cjs
node scripts/verify-site.cjs --git-ref HEAD --http http://127.0.0.1:4198/
```
