# B2B v1 — приёмка интеграции 25.10.2026

Основа: `origin/main` `f57bfae3185f685c18517b81e658d8ca53ea59b8` после согласованного merge Prostor PR #15. Ветка `feature/b2b-case-detail`, маршрут `/raboty/b2b/`. B2B подготовлен для отдельного PR без merge и публикации.

Источники: `SyntheCore_B2B_Git_Integration_Agent_Task_v1.md`, `B2B_Agent_Kit_Light.zip`, отдельное `SyntheCore_B2B_Detail_v1_preview.html`. [Аудит источников, изображений и Git baseline](source-audit.json) фиксирует их SHA. Четыре встроенных WebP, полные тексты процесса/результата и локальный CSS совпали с отдельным превью. PNG в превью заданы относительными путями; для сравнения сервер отдаёт исходные PNG комплекта и действующие локальные Manrope.

## Изменения

Добавлены JSON, два partial hero/result, локальный CSS под `body.sc-case-b2b`, восемь исходных изображений (3 579 972 байта), готовая страница и отдельные тесты/браузерный сценарий. В генераторе зарегистрирован только `b2b-v1` с его собственными slug/catalog_id, четырьмя этапами и четырьмя экранами; проверяемый `full_src` разрешён также B2B. Остальные варианты сохраняют прежний вывод. Слева реестр заявок, в центре обзор, справа платежи; результат — карточка заявки. Четыре PNG 1448 × 1086 доступны через общий lightbox, превью — WebP.

Название **«Кабинет клиента»**, описание, обе метки и SEO берутся из каталога. Результат — интерактивный прототип и MVP ключевых сценариев. Production-запуск, измеренная экономия, рост продаж и реальные финансовые показатели не заявляются. Имена, даты, реквизиты и суммы интерфейсов демонстрационные. Тексты четырёх этапов и результата перенесены дословно.

Главная, каталог и четыре прежних кейса получают только зарегистрированный anchor B2B. B2B исключён из собственных пяти «Других работ», CRM сохраняет модалку. Общие template/CSS/JS, Header/Footer, vendor, 17 motion-файлов и исходные manifests не меняются. В Git нет ZIP, автономного preview, его библиотек, шрифтов или лишних изображений.

Нестандартное изменение QA: старый Prostor snapshot был создан до B2B и отменял только одну позднюю ссылку. Строгий helper теперь отменяет только точные зарегистрированные поздние anchors; неверный URL, дубль и подмена контента проверяются отрицательными тестами. Его исходные SHA и audit сохранены. Дополнительно устранена зависимость SHA-тестов от CRLF рабочей Windows-папки: новая база содержит SHA настоящих Git blobs `f57bfae`, исходные рабочие SHA сохранены отдельно. Только 18 явно перечисленных текстовых файлов учитывают LF/CRLF; ни один motion-файл не нормализуется. Исторический Prostor-тест допускает LF/CRLF только для текстов исходного v27-контракта и двух JSON manifests, сохраняя все их исходные SHA.

Первый браузерный прогон не был принят: hover проверялся до завершения общего scroll-reveal, а PowerShell HTTP-сервер сообщил временный `ERR_NO_BUFFER_SPACE`. Контроль на прежней Beauty воспроизвёл смещение во время reveal и неподвижность после его окончания. Новая проверка дожидается завершения движения перед hover; runtime не менялся. Повтор выполняется последовательно через отдельный Node QA HTTP на 4198, который отдаёт те же файлы проекта. Первичные отклонения и контрольный опыт сохранены в [диагностике](qa-diagnostics.json); никакие ошибки не скрываются фильтрацией отчёта.

## Отличия и ограничения

H1/intro/SEO заменены каталогом по заданию. Заголовок «Кабинет клиента» короче автономного «B2B-кабинет для клиентов», поэтому переносы и вертикальное положение следующих секций отличаются. Размеры локальной композиции, типографика и движение берутся из утверждённого v1 и текущего v20. Прочие структурные отличия автономного окружения — действующие общие Header/Footer, CTA и актуальные карточки вместо их копий в preview.

Проверялся Chromium с эмуляцией размеров и touch. Firefox/WebKit, реальные устройства и субъективная плавность физической мышью/тачпадом не проверялись. Пиксельная идентичность всех страниц не заявляется. Предыдущая незавершённая предпроверка исходного ZIP не выдана за успешную интеграционную приёмку.

## Воспроизведение

Нужна существующая локальная установка Playwright. Текущий QA HTTP — 4198 (те же файлы, что локалка на 4176), предоставленное превью — 4196, базовый main-экспорт — 4197. Через `SYNTHECORE_URL`, `B2B_REFERENCE_URL`, `B2B_BASELINE_URL` можно указать другие адреса. Локальные экспорты/серверы и браузер в production не входят.

```powershell
node scripts/build-site.cjs --check
node --test scripts/test-b2b-case.cjs scripts/test-prostor-case.cjs
$env:SYNTHECORE_URL = 'http://127.0.0.1:4198/'
node scripts/verify-b2b-browser.cjs
$env:CASE_PROJECT = 'b2b'
node scripts/verify-case-links-browser.cjs
node scripts/verify-site.cjs --git-ref HEAD --http http://127.0.0.1:4198/
```

Полный список изменённых файлов: [changed-files.txt](changed-files.txt). Приёмка относится к этой интеграции и не подменяет исторические отчёты.
