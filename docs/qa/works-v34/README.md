# Works v34 — геометрия Hero

База: `91235aa239d49effb90bde72409d6f6f5db49e7b` после PR #18. Версия v34 относится к геометрии Works поверх согласованного сайта v62/v27. Изменения подготовлены в `feature/works-hero-geometry-v34`; merge и публикация не разрешены.

## Причины и исправление

Ширина Works раньше вычислялась от `100vw` с местом под scrollbar, а затем помещалась в более узкого родителя. Высота выводилась из пропорции картинки и дополнительно менялась отдельными mobile-правилами. У Hero были другие размеры, отступы и радиусы.

Теперь существующие размеры Hero вынесены в общие `--hero-edge`, `--hero-surface-height`, `--hero-surface-radius`. Frame Works занимает 100% внутреннего контейнера; старые `--works-width`, `--works-aspect`, padding и конфликтующие mobile-расчёты удалены из исходного компонента. Изображения сохранили `object-fit:cover` и прежние object-position. Индивидуальных поправок для шести работ нет.

На коротком мобильном экране Hero с `height:auto` может быть выше `100svh`. Один ResizeObserver в существующем Works-компоненте передаёт фактическую высоту Hero всем шести карточкам через `--hero-used-height`, не меняя Hero. Resize пересобирает ту же timeline через существующий setup: прежний refresh оставлял старые GSAP startAt, которые возвращались при обратной прокрутке. Скорости, ease, масштабы, стеклянные плашки и их tween сохранены. Последняя карточка удерживается дополнительными 30svh в прежней CSS sticky-сцене; сами переходы не растянуты. По уточнению владельца 27.10.2026 удержание сокращено с 50svh до 30svh вместо прежнего минимума в половину экрана.

## Исходники и контроль

Основные файлы: `css/main.css` (единые параметры), `css/works.css` (общий frame), `css/sticky-handoff-v61.css` (сцена и hold), `js/works.js` (фактическая высота и resize). `css/generated/home.css` пересобран штатным генератором, вручную не редактировался. Шаблоны, HTML-тексты, порядок шести работ, медиа, Header/Footer, навигация и библиотеки не менялись.

Исходные SHA-манифесты сохранены. Контракт: **13 raw motion-файлов + четыре точных разрешённых изменения**. `approved-works-geometry.json` и helper отменяют только зарегистрированный diff с сохранением LF/CRLF, затем требуют полный прежний SHA. Лишние CSS, неверные размеры/ease/плашки/тайминги, изменения соседей и stale bundle отвергаются отрицательными тестами и отдельным временным Git index. Исторический архивный `--strict` не является PASS-контрактом v34.

## Повторить и посмотреть

```powershell
node scripts/build-site.cjs --check
node scripts/export-works-v34.cjs
node scripts/verify-works-v34-browser.cjs
node --test scripts/test-works-hero-geometry.cjs scripts/test-works-v34-contract.cjs scripts/test-works-v34-preview.cjs
node scripts/verify-site.cjs
```

Перед коммитом последняя команда проверяет index; после коммита используйте `--git-ref HEAD`. Локалка — 4176, другой адрес задаётся через `SYNTHECORE_URL` для браузерного QA.

Обзорная сборка: `output/works-v34/SyntheCore_Works_v34.html`. В неё встроены локальные CSS/JS, картинки и шрифты текущего сайта; исходный Google Fonts import сохранён. Локальные якоря остаются внутри артефакта, переходы к другим страницам используют локалку 4176. Этот HTML не является релизным исходником и не коммитится. Для отката сохранён Git-коммит `91235aa`, входной v33 не изменялся.

Проверки выполняются в Chromium; эмуляция и автоматический scroll не доказывают физическую плавность мыши/тачпада или производительность реального устройства. Без JS карточки остаются в обычном потоке; на дополнительных коротких мобильных окнах CSS-fallback использует общую минимальную высоту, поскольку фактическую intrinsic-высоту Hero без JS передать нельзя. На четырёх контрольных размерах fallback также совпадает с Hero.
