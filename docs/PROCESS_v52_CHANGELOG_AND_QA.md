# SyntheCore v52 — анимация иллюстрации в блоке «3 шага до запуска»

Основа: v51 (интеграционная сборка на основе контрольной v46). Дата: 16.10.2026.

## Изменения
- `index.html`: только обёртки `sc-process__art-parallax`, `sc-process__art-float` вокруг прежней иллюстрации. Новый блок остаётся после `#services` и до `#contact`.
- `css/process.css`: добавлены два независимых слоя движения — мягкое парение PNG по вертикали (амплитуда 9px, период ~11.6s туда-обратно, 5.8s в одном направлении) и перемещение по скроллу (до ±10px), без изменения масштаба.
- `js/process.js`: отдельное пассивное отслеживание прокрутки с `requestAnimationFrame` и `IntersectionObserver`. Не изменяет GSAP, Lenis, старые секции, порядок элементов или обработчики шагов.
- Оба эффекта отключены при `prefers-reduced-motion: reduce`.

## Не изменялось
Все файлы Hero, «С кем работаем», Works, Services, Contact, PNG фон, PNG/WebP иллюстрация, заголовки и тексты, оранжевая подсветка трёх шагов.

## Проверка
- Node: `check-project`, `verify-works-static`, `verify-works-timeline-v43`, `verify-works-handoff-v45`, `verify-services-static` + `node --check` для JS — все успешны.
- Отдельная Chromium-проверка блока 1920, 1440, 1200, 1024, 768, 390, 320: PASS. Проверены parallax в обе стороны, `font-weight:400`, сохранение натурального PNG 1228×793, отсутствие горизонтального переполнения, интерактивность шагов и reduced motion.
- Smoke-проверка всей страницы через автономный HTML на 1440×900 и 390×844: PASS. Подтверждены секции в порядке Hero → Audiences → Works → Services → Process → Contact, доступность прежних Works/Services, инициализация существующих ScrollTrigger, активность эффекта при скролле, исправность кнопок и отсутствие ошибок JavaScript / переполнения.
- Полный регрессионный проход всего сайта со scroll pin (Hero/Works/Services) в реальном локальном сервере остаётся открытой проверкой; v51 также не проходила такую приёмку.

Статус: кандидат на локальную приёмку. В Git не переносилось, на production не публиковалось.
