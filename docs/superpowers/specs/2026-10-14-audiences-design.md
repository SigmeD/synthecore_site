# «С кем работаем»: пропорции и карточка

> **Архив до рефакторинга v31.** Этот документ сохраняет постановку, реализацию и результаты своей итерации. Его слова «актуально» и «проверено» не являются приёмкой текущей страницы. Текущий вход: [старт v31](../../01_NEW_CHAT_START.md), [QA v31](../../QA_V31.md). Пути «локальный артефакт» обозначают материалы вне Git, которые могут отсутствовать в клоне.

Основание — семь пунктов задания пользователя. Новые секции, библиотеки и контент не нужны. Работа только внутри #audiences; Hero и меню остаются прежними.

Сохранить контейнер 1200px, сделать настоящие desktop-колонки: список слева, карточка справа с общими границами. Заголовок 32px/38.4px и отступ36px. Названия остаются крупными, но получают вес 300. На узких экранах — одна колонка, карточка появляется под списком.

Карточка шире прежней узкой модели, отступы24–32px, компактные интервалы. Вместо абсолютного flex-контента внутри фиксированной высоты — три статьи в одной ячейке CSS grid; высота определяется самой длинной из трёх статей. Это предотвращает обрезание и скачок размеров при переключении. Изображение содержит исходные пропорции, object-fit contain, flex shrink исключён; размер уменьшается примерно на 15–20% относительно соответствующего baseline. Существующие цвета, картинки и переходы opacity/transform сохраняются.

Удалить только span «Смотреть ↗» из каждого существующего button. Вся строка уже является кнопкой; существующие hover/tap, ArrowUp/Down, Enter/Space, Escape и aria/inert сохраняются. Теги без рамок и padding, в одну строку, исходные подписи без дополнений. Текст карточки16px/1.5, обычный вес 400.

Проверить одинаковый1920×1080 для live Roveia и SyntheCore; до/после на1366×768,1920×1080,3840×2160,390×844,430×932. Все три активные статьи, отсутствие overflow/обрезания, клавиатура и touch, native reduced motion. Для соседей — сравнить исходный HTML вне #audiences, JS и CSS-блоки вне audience-правок с backup, а также Hero-геометрию в браузере.

Спецификация следует заданию пользователя; отдельное подтверждение уже описанных правок не требуется. Git отсутствует; исходные файлы сохранены в backup/audiences-before-2026-10-14.
