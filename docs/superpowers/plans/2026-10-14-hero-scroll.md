# Hero scroll — implementation plan

> **Архив до рефакторинга v31.** Этот документ сохраняет постановку, реализацию и результаты своей итерации. Его слова «актуально» и «проверено» не являются приёмкой текущей страницы. Текущий вход: [старт v31](../../01_NEW_CHAT_START.md), [QA v31](../../QA_V31.md). Пути «локальный артефакт» обозначают материалы вне Git, которые могут отсутствовать в клоне.

**Goal:** реализовать заданную плавную прокрутку без изменения дизайна и подтвердить её в браузере.

**Architecture:** один GSAP ticker, Lenis для окна, одна Timeline для Hero. Локальные фиксированные зависимости; при отказе библиотек — нативная прокрутка со статичным фото.

**Tech Stack:** vanilla HTML/CSS/JS, GSAP/ScrollTrigger 3.12.5, Lenis 1.3.26, Node для воспроизводимых проверок, Playwright для браузерной приёмки.

Работа выполняется прямо в авторизованной папке, без worktree: Git отсутствует, контрольная копия — `backup/v23.1-before-lenis/`. Задание пользователя служит согласованным spec. План исполняется в текущем сеансе.
