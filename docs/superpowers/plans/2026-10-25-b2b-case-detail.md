# Интеграция B2B v1

**Цель:** `/raboty/b2b/` через общий генератор v20, с названием «Кабинет клиента» из каталога, четырьмя этапами и четырьмя исходными интерфейсами. Дизайн и объём утверждены MD-заданием владельца; это интеграция, а не новый дизайн.

**База:** `origin/main` `f57bfae3185f685c18517b81e658d8ca53ea59b8`, после согласованного слияния Prostor PR #15. Обычная ветка `feature/b2b-case-detail` в основной папке; worktree не нужен. Последняя ревизия документации 21.10.2026, следующая 04.11 ещё не требуется.

**Источники:** внешний MD, `B2B_Agent_Kit_Light.zip` (включает source HTML/CSS и восемь изображений), отдельный `SyntheCore_B2B_Detail_v1_preview.html`. Сверить полные тексты и SHA экранов между комплектом и превью. Исходные файлы остаются в ignored output.

## Решения до кода

- Четыре этапа и результат переносятся дословно из HTML. Подтверждены прототип и MVP, но не production-запуск или измеренный эффект. Числа/имена/даты/реквизиты экранов демонстрационные.
- Для точного первого блока/результата нужны локальные классы и CSS: размеры B2B отличаются от базового Beauty. Использовать `variant: b2b-v1`, `hero-b2b.html`, `result-b2b.html`, `case-b2b.css` под `body.sc-case-b2b`; общий HTML-каркас, CSS и весь runtime JS остаются прежними.
- Текущий `full_src` разрешён только Prostor. Разрешить его также только B2B, с прежними проверками локального пути/существования; четыре превью WebP и четыре PNG. Число экранов прежних вариантов не меняется.
- Главная, каталог и четыре прежних кейса получают только автоматически созданный anchor B2B. CRM сохраняет модалку.
- Старый тест Prostor отменяет только anchor Prostor перед сравнением с SHA базы без него. Дополнить точной отменой зарегистрированного B2B anchor через общий QA-helper, сохранив исходные SHA и отрицательные проверки URL/дублей/контента. Не ослаблять manifests и runtime-контракты.
