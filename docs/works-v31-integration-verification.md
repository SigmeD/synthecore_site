- Chromium 1024x768: PASS — все шесть изображений загружены при достижении карточек; подписи помещаются в рамку и viewport; горизонтального переполнения нет.

На каждом размере проверены прокрутка вниз через все карточки до услуг и контактов, обратный проход, быстрая смена направления, остановка без дрейфа, resize, Home/PageDown, переход «Работы» и соответствующая desktop/mobile навигация. На 390×844 и 320×700 дополнительно проверен настоящий эмулированный touch через CDP.

На каждом размере переключение prefers-reduced-motion убирает sticky/масштабирование, удаляет все шесть Works ScrollTrigger; возврат создаёт ровно шесть, без дублей. Инструментирование конструктора/уничтожения Lenis подтвердило максимум один живой экземпляр, в native/reduced-motion — ноль. Карточки достигают масштаба 1; последняя рамка освобождает место услугам. Новых библиотек и обработчиков в существующем коде нет.

Отдельные сценарии: первоначальный URL #works, переход к #services после работ, history back, задержка изображений на 1200 ms, resize 1440→390→1440 — PASS. Якоря учитывают существующий scroll-padding-top:115px. Отсутствие GSAP и отдельное отсутствие ScrollTrigger проверены с чтением всех шести карточек: fallback no-gsap, ошибок JavaScript нет.

Консольных ошибок, pageerror, неудачных запросов и HTTP ≥400 в основной матрице не обнаружено. Проверки node --check прошли для 40 существующих JS-файлов и нового works.js. `node scripts/check-hero-geometry.cjs`: PASS (12 сочетаний изображения/viewport, 60 состояний). `git diff --check`: PASS.
