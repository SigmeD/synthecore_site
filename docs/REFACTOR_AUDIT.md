## Стили

До правки: 27 CSS-файлов, 203 881 байт, полных дубликатов нет. Все файлы используются. На уровне CSSOM обнаружены 1 486 style-правил, 27 групп полностью одинаковых правил и 152 группы повторяющихся селекторов с учётом контекста media/supports. Повтор селектора сам по себе не доказывает лишний код: важны порядок каскада, промежуточные объявления и разные страницы. Эти правила автоматически не удалялись.

На главной теперь одно подключение `/css/generated/home.css` вместо 18. Сборщик разворачивает 18 входных файлов и локальный импорт политики кнопок в прежнем порядке (19 входов), переписывает относительные URL ресурсов и формирует воспроизводимый файл размером 122 879 байт. Библиотеки и их версии сохранены. Минификации и удаления повторов нет.

Все 27 модульных исходников сохранены побайтно. Каталог и кейсы используют разные наборы правил, поэтому сохраняют свои подключения; стили этих страниц не добавляются в главную. Объединение исходников в один редактируемый файл ухудшило бы изоляцию страниц и нарушило заморозку. Практический результат — один файл доставки главной при прежней структуре редактирования.

Исходный Google Fonts import сохранён с тем же URL. Он помещается перед обычными правилами: иначе браузер игнорирует поздний `@import` ([CSS Cascade](https://www.w3.org/TR/css-cascade-5/#at-import)). Сборка разрешает только существующий URL; перенос через предшествующий `@font-face`, циклы, неизвестные внешние импорты, выход за корень и неподдерживаемый синтаксис отклоняются. Это целевой сборщик текущих исходников, а не универсальный CSS-парсер. При добавлении нового синтаксиса нужно расширить проверку и тесты либо выбрать подходящий сборщик.

Редактировать нужно исходные модули, затем выполнять `node scripts/build-site.cjs`. Готовый CSS и HTML коммитятся вместе. Ручная правка результата обнаруживается `--check`. Проверка Git дополнительно пересобирает CSS из blobs того же index/коммита: корректные файлы на диске не могут скрыть испорченный артефакт в коммите. Допускается только точная замена прежних 18 CSS-тегов одним утверждённым тегом; лишние, отсутствующие и подменённые подключения отклоняются.
