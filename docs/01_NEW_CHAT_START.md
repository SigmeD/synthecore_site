## Проверки и изменение шаблонов

Команды приведены в [README](../README.md) и [реестре](../scripts/HISTORICAL_CHECKS.md). Минимальный контракт после изменения, затрагивающего сборку:

```powershell
node scripts/verify-v62-import.cjs
node docs/qa/v62-on-v27/verify-git.cjs HEAD
node scripts/build-site.cjs --check
node --test scripts/test-static-checks.cjs scripts/test-shared-site.cjs
```

Git-проверка с `HEAD` проверяет коммит, без аргумента — индекс. Она не заменяет проверку изменённой рабочей папки. Использовать `core.autocrlf=false`, чтобы сохранить точные LF/CRLF motion-файлов. `.gitattributes` защищает байты ассетов/библиотек/локальных шрифтов.

HTML генерируется из `templates/pages/` и `templates/partials/`. Только если задание разрешает изменение, после него выполнить `node scripts/build-site.cjs` и сохранить соответствующие HTML. Не править сгенерированный HTML отдельно от шаблона. Меню на главной уже обслуживает защищённый `main.js`; на каталоге — `site-header.js`, не оба одновременно.
