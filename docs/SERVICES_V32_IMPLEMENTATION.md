# SyntheCore — блок «Что мы делаем» v32 (рабочая версия)

## Что изменилось

- Заменена временная секция `#services` после `#works` на блок шести карточек услуг.
- `css/services.css` — все новые правила строго внутри `.sc-services`.
- `js/services.js` — горизонтальная прокрутка карточек; нет новых Lenis, GSAP или ScrollTrigger.
- `assets/services/*.svg` — шесть оригинальных монохромных векторных иллюстраций, созданных для блока.
- `index.html` — подключение новых файлов и контент вместо заглушки.

Всё остальное (Hero, «С кем работаем», все шесть работ, контактный footer, существующие JS и CSS) оставлено без изменений.

## Дизайн / референс

Композиция основана на скриншоте Roveia «What We Do» (15.10.2026): белая секция, много пространства, горизонтальный ряд серых карточек, монохромные иллюстрации, заголовки, теги, короткое описание. Код и чужие изображения не копировались.

## Действия

- Desktop: нативный горизонтальный скролл trackpad, перетаскивание мышью и кнопки ← →; обычное вертикальное колесо продолжает листать страницу.
- Mobile: нативный свайп, кнопки ← →, snap по карточкам.
- Клавиатура: focus на списке + Left/Right/Home/End.
- `prefers-reduced-motion`: отключены переходы.
- При недоступном JS карточки остаются в нативном горизонтальном скролле.

## Что необходимо согласовать

Контент услуг — первая рабочая редакция. Нужно проверить названия, состав и порядок с точки зрения продаж SyntheCore до слияния ветки.

Протестировать не только этот блок, но и вход/выход из Works (вниз и обратно), якоря `#services/#works`, на разрешениях 320/390/768/1440/1920, touch/desktop, reduced motion, без JS; проверить отсутствие горизонтального overflow страницы. Дополнительно прогнать существующие `node scripts/check-project.cjs`, `node scripts/verify-works-static.cjs` и `node scripts/test-static-checks.cjs`.
