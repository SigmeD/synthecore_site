# SyntheCore — Services v36: аудит и передача

**Источник:** утверждённый проект v35. Работы, Hero, аудитории и их JavaScript не менялись.

## Исправления

- Для каждой из шести услуг теперь две самостоятельные векторные иконки: `name-mono.svg` (неактивная серая) и `name.svg` (активная оранжевая). Оба файла с идентичной геометрией и прозрачным фоном.
- Размер иконок уменьшен до 85% от прежнего занятого пространства. На ширине 1440 px иконки показаны в едином размере и пропорциях.
- Убрана обёртка `.sc-service-card__art`. Два изображения находятся непосредственно в `<article>` с общим `grid-area`; текст занимает отдельную строку grid.
- В неактивном состоянии видна только серая иконка; при hover/focus — только оранжевая; переключение мягкое, без скачка геометрии. Сохранился голубой градиент из Hero, включается только на активной карточке.
- Высота текстовой зоны выровнена (`min-height:190px`), поэтому заголовки всех шести карточек идут по общей линии на протестированных разрешениях.
- Адаптивный горизонтальный ряд и pinned-анимация GSAP, принадлежащая секции услуг, не менялись; вертикальный скролл не перехватывается. Второй Lenis не создавался.
- Обновлён `verify-services-static.cjs`: проверяет **12 изображений**, по паре на карточку. Манифест ассетов содержит все двенадцать SVG.

## Проверки

- `node scripts/verify-services-static.cjs` — PASS.
- `node scripts/verify-works-static.cjs` — PASS (шесть утверждённых Works-изображений).
- `node scripts/check-project.cjs` — PASS (структура, ресурсы, asset/vendor manifest).
- Chromium: автономный HTML через `page.set_content`, ширины 1440, 390 и 320 px; на 1920 px проверена геометрия. На 1440 px подтверждены CSS `opacity:1/0` в неактивном и `0/1` в hover, правильный фон Hero, загрузка обеих иконок, отсутствие pageerror и горизонтального переполнения страницы.
- На ширинах 320, 390, 1440, 1920 заголовки всех шести карточек выровнены на одной линии.

## Ограничения и риски

- Полноценное повторное тестирование на реальных мобильных устройствах и в deployment не выполнялось. Локальный HTTP blocked by browser administrator, поэтому проверка Chromium выполнена на автономном HTML.
- На touch-устройствах постоянного hover нет, остаётся монохромное неактивное состояние; цвет кратковременно включается при касании, что не препятствует свайпу.
- В оригинальных скриншотах DOM Roveia виден `filter:saturate(...)` у элемента `img`. Это не доказывает наличие двух **файлов** в референсе. Два физических файла сделаны по запросу SyntheCore.
- Новые SVG — векторные объёмные иллюстрации v35, а не отдельные фотореалистичные 3D-рендеры. Новая геометрия не генерировалась: для пары идентична исходная форма.
