# SyntheCore v39 — корректировка перехода Works → Services

**База:** v38. **Дата:** 16.10.2026. **Цель:** убрать длинную остановку шестой карточки и внешнюю тень при её уходе, не менять уже утверждённые карточки, контент, горизонтальную анимацию услуг и Hero.

## Найденная причина

- В `css/works.css` у `.sc-works` стояло `--works-last-hold:85svh`. Псевдоэлемент `.sc-works-stack::after` резервировал эту высоту после последней карточки, увеличивая время, в течение которого последняя работа стоит на месте.
- Правило `.sc-work-item--front .sc-work-frame` задавало наружную тень для видимой работы. В переходе от шестой карточки её края и внешняя тень оставались заметными дольше нужного. Тень стеклянной подписи `.sc-work-content` — отдельный эффект внутри карточки.

## Исправления

1. `--works-last-hold` сокращён **с 85svh до 12svh**. При viewport 900 px это 765 → 108 px. Небольшой интервал оставлен, чтобы последняя карточка успела занять своё место перед уходом, без длительной остановки.
2. Добавлено `.sc-work-item:last-child .sc-work-frame {box-shadow:none}`. Для первых пяти карточек тени сохранены. На стеклянной подписи ничего не менялось.
3. Никаких изменений в `index.html`, `js/works.js`, `js/services.js`, `css/services.css`, Hero и глобальном скролле.

## Проверка

- Статика: `verify-works-static.cjs`, `verify-services-static.cjs`, `check-project.cjs` и новый `verify-works-services-transition-v39.cjs` — PASS.
- Chromium: desktop 1440×900, 1920×1080 — фазы approaching, last_stays, releasing, entering, pin, back; JS ошибок нет, у последней карточки `getComputedStyle(frame).boxShadow === 'none'`.
- Chromium: 390×844, 320×700 — нативная лента услуг, без горизонтального переполнения страницы, JS ошибок нет.
- Chromium 1440×900 с `prefers-reduced-motion:reduce` — нативная прокрутка без пина, JS ошибок нет.
- Геометрия: в 1440×900 последний кадр переходит с `top:12px` на `top:-66px` между контрольными точками за 130 px прокрутки. Услуги затем входят в экран и закрепляются без скачка при обратной прокрутке.
- Скриншоты: `SyntheCore_v39_last_stays.png`, `SyntheCore_v39_releasing.png`, `SyntheCore_v39_entering.png`, `SyntheCore_v39_pin.png`, `SyntheCore_v39_back.png`.

## Ограничения

Проверка проводилась в headless Chromium на автономном HTML со встроенными ресурсами. На физическом телефоне, Safari и продакшен-сервере версия пока не проверена. Текущий переход остаётся сценой из двух независимых GSAP/CSS-секций; отдельная автоматизация непрерывного видео-теста на всех устройствах не проводилась.
