# SyntheCore v57 — отзывы и стык с блоком «3 шага до запуска»

**База:** v56. **Состояние:** интеграционная версия для согласования, не production.

## Изменения

1. Сцена теперь имеет высоту `475svh` на широком десктопе. Пока заголовок остаётся по центру в CSS `sticky`, четыре карточки идут справа налево по одной непрерывной шкале вертикальной прокрутки. Скорость движения зависит от ширины экрана и длины сцены; 4 отзыва идут последовательно и частично перекрываются по времени.
2. Убрано исчезновение карточек: у каждой `opacity: 1` на всём пути, на выходе её целиком скрывает `overflow:hidden` сцены. Заголовок также всё время непрозрачен (`opacity:1`).
3. Вход начинается до полного ухода предыдущего баннера. Первая карточка уже частично видна у правого края. Заголовок сдвигается в центральное положение без изменения прозрачности. Прежний баннер слегка поднимается и уменьшается, не становится полупрозрачным.
4. Для точного совмещения перехода по референсу на desktop **только если сразу после `#process` идёт `#testimonials`** высота process-баннера ограничена `clamp(580px,66svh,690px)`, уменьшены вертикальные padding внутреннего контейнера и нижнее поле секции. Эти CSS-переопределения находятся в `css/testimonials.css`, чтобы не менять исходный `css/process.css`.
5. Движение за указателем прокрутки сглажено по времени (постоянная ~0.24 c, через `requestAnimationFrame`). Анимация лёгкого парения внутри карточек и увеличение при hover сохранены.
6. Нет дополнительного `GSAP pin`, перехвата wheel или изменения Lenis. На планшетах/телефонах остаётся горизонтальная лента; при `prefers-reduced-motion` — статический режим.

## Изменённые файлы

- `css/testimonials.css` — геометрия сцены и локальная коррекция стыка с баннером.
- `js/testimonials.js` — начальные позиции, непрозрачные траектории, общая шкала прокрутки и сглаживание.
- `README.md` — версия и статус.
- `docs/TESTIMONIALS_V57_QA.md` — текущий отчёт.

Остальные HTML, JS, CSS и ассеты v56 не менялись.

## Проверки

- `node --check js/testimonials.js` — PASS.
- `node --test scripts/test-static-checks.cjs` — **69/69 PASS**.
- Chromium с полной автономной страницей: 1440×900, 1920×1080, 1280×800, 1100×720, 768×1024, 390×844 — PASS для отображения, отсутствия ошибок JavaScript/горизонтального переполнения и корректного режима сцены. На трёх десктопных размерах проверено движение карточек по этапам, непрозрачность, выход через левую границу, обратная прокрутка, отсутствие нового `pin`.
- Chromium в облегчённом HTML: 320×700 — нативная лента, без ошибок и горизонтального переполнения. При `prefers-reduced-motion: reduce` на 1440×900 — нативная лента, без ошибок и горизонтального переполнения.
- Пробный запуск страницы через `http://127.0.0.1` невозможен: тестовый Chromium получает `ERR_BLOCKED_BY_ADMINISTRATOR`. Проверка браузера выполнена на автономной HTML-копии с идентичными CSS/JS; локальная приемка на машине разработчика остаётся обязательной.

## Что проверить до публикации

1. Медленно прокрутить весь сайт вниз и вверх через Works → Services → Process → Testimonials → Contacts в локальном браузере.
2. На 1440, 1920 и 1280 px проверить длительность движения и читаемость карточек при наведении.
3. На мобильных 390/320 px проверить перелистывание пальцем и отсутствие sticky.
4. Перед публикацией заменить **все демонстрационные отзывы, имена и иллюстрации** подтверждёнными материалами и согласовать их использование.
5. После согласования проверить производительность на реальных устройствах; уменьшить длительность/нагрузку, если прокрутка выглядит тяжёлой.

**Зафиксированное ограничение:** сейчас анимация рассчитана на 4 карточки. Изменение количества отзывов потребует отдельной проверки длительности и композиции.
