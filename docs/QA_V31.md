- Из `css/main.css` удалены 22 целых правила несуществующих DOM-состояний, один мёртвый селектор из reduced-motion списка и два пустых media-блока; файл уменьшился на 3562 байт. Порядок оставшегося каскада сохранён. Полная [карта удалений](CSS_CASCADE_V31.md) содержит исходные selector lists, media contexts, specificity и вычисленные размеры.
- В `index.html` исправлены только номер сборки в title (v23→v31) и устаревший служебный HTML-комментарий. Разметка и содержимое секций не изменялись.
- Старое требование полного совпадения HTML с pre-Works версией заменено текущими структурными и ресурсными проверками. Добавлены проверки неизменных текстов кейсов, PNG hashes/dimensions, уникальных ID/подключений, порядка секций/библиотек, якорей, единственного исходного владельца Lenis; HTTP-проверка явно включается опцией.
- Текущие README/архитектура/механика/changelog отделены от исторических отчётов. 141 ссылка на отсутствующие в Git локальные материалы заменена помеченными code-путями. Исторические сценарии перечислены в [реестре](../scripts/HISTORICAL_CHECKS.md).

## Сохранено

Все четыре runtime JS, `css/works.css`, исходные шесть изображений, тексты/статусы/aria-разметка карточек и локальные библиотеки сохранены побайтно. Не менялись размеры, прозрачность стекла, радиусы, тени, кадрирование, sticky/масштабирование, Hero pin/reveal, аудитории, меню, CTA и контакты. Аудит JS и стресс-проверки не выявили необходимости переписывать проверенные алгоритмы. Жизненный цикл описан в [SCROLL_MECHANICS](SCROLL_MECHANICS.md); очистка source JS ради переименований не выполнялась. Сложные действующие поздние CSS overrides оставлены как обоснованный долг.

## Ограничения и объяснённые расхождения

1. Firefox: строгое PNG-сравнение различает один пиксель (координата 913,487, максимум 18/255 по каналу) в мелком тексте открытой первой аудитории. То же отличие дважды воспроизведено с **исходным** CSS и дважды с очищенным; вычисленные стили одинаковы. Строгий failed-report сохранён, не переименован в passed. Отдельный полный функциональный прогон Firefox прошёл все 16 состояний. Полное попиксельное совпадение Firefox не заявляется.
2. Blink на 320 px иногда сериализует flex auto margin как 0px вместо использованных 20px. Это воспроизведено и с исходным CSS; PNG SHA-256, x=30 и width=260 остаются одинаковыми. Проверка сравнивает семантическое auto из Typed OM, дополнительно требует фактического центрирования и сохраняет строгое побайтное PNG-сравнение. Первоначальное ложное падение computed-style сравнения сохранено в сыром отчёте; целевой повтор 320×700 прошёл 14/14.
3. Safari как пользовательское приложение и реальные устройства не запускались. WebKit — установленный Playwright engine; mobile — эмуляция viewport/touch Chromium. Формального FPS/WCAG-аудита нет.
4. Применён строгий tokenizer явного статического HTML без HTML5 error recovery. Source guard Lenis покрывает обычные constructor-вызовы; aliases/dynamic code требуют браузерного контроля. Default Node --test subprocess блокируется sandbox, поэтому node:test suite запускается напрямую через node и выводит реальные TAP/summary.
5. Исторические browser-скрипты не являются текущей приёмкой и могут падать на v31. Ссылки на их локальные доказательства намеренно не выдаются за доступные файлы репозитория.

## Воспроизведение

Для offline проверок достаточно Node с встроенными fetch/AbortSignal.timeout (проверено Node 24.11.1). Приложению Node не нужен. Для browser suite нужен уже установленный Playwright/его engines и работающий локальный HTTP server.

```powershell
node scripts/check-project.cjs
node scripts/verify-works-static.cjs
node scripts/test-static-checks.cjs
node scripts/check-project.cjs --http http://127.0.0.1:4173/
git ls-files --cached --others --exclude-standard | node scripts/check-doc-links.cjs
node scripts/verify-v31-browser.cjs --capture=before
# После проверяемой группы CSS/JS правок:
node scripts/verify-v31-browser.cjs --capture=after
node scripts/verify-v31-browser.cjs --capture=after --stress-only
node scripts/verify-v31-browser.cjs --capture=after --fallbacks-only
node scripts/verify-v31-browser.cjs --capture=before --video-only
```

Фильтр размера: `--only=390x844`. Другой engine: `--engine=firefox` или `--engine=webkit`; для снимков сначала создайте собственную before-базу данного engine. `--capture=audit` сохраняет функциональную матрицу без сравнения; `--capture=after --functional-only` явно выполняет функциональность отдельно и не выдаёт её за визуальную проверку. Адрес сайта меняется через SYNTHECORE_URL.

Рефакторинг подготовлен к отдельной приёмке. Раздел «Что мы делаем» не добавлялся; его реализация остаётся отдельной задачей.
