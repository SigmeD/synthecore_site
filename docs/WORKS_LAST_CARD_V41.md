# SyntheCore v41 — последняя карточка «Наши работы»

**База:** v40. **Статус:** исправлено в локальной сборке, в Git не переносилось.

## Причина

В v40 первые пять `.sc-work-item` занимали `145svh`, но последняя карточка была укорочена до высоты медиа (`--works-height` + отступы). У последнего sticky-элемента вместе с финальным промежутком `12svh` оставалось менее одного экрана высоты. CSS sticky ограничивается нижней границей родительского контейнера, поэтому шестую карточку начинало выталкивать вверх **до того**, как её верх доходил до верхней позиции остальных пяти карточек. Внешние тени здесь уже были отключены и к ошибке не относились.

## Изменение

Только в `css/works.css`:

```css
.sc-work-item:last-child {
  height:100svh;
  flex-basis:100svh;
}
```

Короткий завершающий промежуток `--works-last-hold:12svh` оставлен. Шестая карточка теперь:

1. заходит поверх предыдущей и проходит тот же scale-scrub;
2. доходит до `top:0` и полностью выравнивается;
3. ненадолго задерживается;
4. уходит вверх вместе с завершением Works, уступая место Services.

`margin-top` услуг остаётся нулевым. CSS и JS секции услуг, `works.js`, Hero, изображения, текст, иконки и тени не менялись. Для режима reduced motion работает существующий fallback с обычным потоком.

## Проверки

- Статические: `verify-works-static.cjs`, `verify-services-static.cjs`, `verify-works-shadow-v40.cjs`, `check-project.cjs` — PASS.
- Chromium (автономный HTML): 1440×900, 1920×1080, 390×844, 320×700; 1440×900 в режиме reduced motion.
- На обычной прокрутке шестая карточка приходит к `top:0`, остаётся там ещё на ~6.5% высоты экрана и после ~12% высоты начинает выходить.
- Прокрутка обратно возвращает последнюю карточку к `top:0`.
- Внешних теней у всех шести карточек нет. Ошибок JS и горизонтального переполнения в проверенных сценариях нет.

Подробные замеры — `SyntheCore_v41_Final_QA.json` (приложен рядом с архивами).

**Ограничения:** физические устройства, Safari и production-сервер не проверены. При интеграции проверить поведение с реальным Lenis-потоком колеса и при изменении высоты окна. Не заменять целевой репозиторий архивом целиком; переносить изменённый CSS выборочно.
