# SyntheCore — v61 / визуальное применение дизайн-системы v0.2

**Статус:** кандидат для просмотра; не утвержден и не загружен в Git.
**Источник:** актуальная v60 из `synthecore.rar`, извлечена без `.git`, `backup`, `output`.

## Что применено
- Предлагаемая шкала из части B v0.2: H1 72/52/36, основные H2 64/48/34, H3 40/34/28, карточки 32/28/24, body 18/17/16, breakpoint 991/767px.
- `Manrope` подключён через Google Fonts как **экспериментальная** гарнитура, с Inter/системным fallback. Для автономной публикации потребуется утверждение источника и загрузки шрифта.
- На существующих компонентах: заголовок hero, аудитории, услуги, этапы, отзывы, FAQ, CTA футера; обновлены ширина хедера, вертикальный ритм в обычных секциях, типографика карточек.
- Сохранены цвета, изображения, тексты, порядок секций, GSAP/ScrollTrigger/Lenis, структура DOM и анимационные скрипты v60.

## Что намеренно не переносилось буквально
- Шкала тегов Roveia H1=140 / H2=96 и его несогласованная HTML-семантика.
- Принудительная нормализация `.sc-works` и `.sc-testimonials` по padding: эти сцены зависят от scroll-геометрии.
- Резкая смена геометрии hero и размеров карточек услуг; без поэтапной визуальной проверки это рискованно.
- Изменения текстов и утвержденных CTA.

## Технически
- Изменён только `index.html` (подключение нового стиля и заголовок окна).
- Добавлен `css/design-system-v61.css`. Это последний CSS и полностью изолированный слой отката.
- Остальные исполняемые файлы v60 не редактировались.

## Оценка риска
- Для фиксированной шапки отдельные секции получили дополнительное пространство сверху (аудитории, мобильные услуги, FAQ) — это обоснованное исключение из базовых 96/72/56 px.
- На 4K, ultrawide и при маленькой высоте окна необходимо визуально проверить hero, переходы закреплённых блоков, длину строк русского текста.
- Внешний Manrope потребует интернета; при отсутствии соединения корректный fallback — Inter.
- Не считать замеры прототипа доказательством одинаковой scroll-физики на всех устройствах. После утверждения нужен полный браузерный аудит.
