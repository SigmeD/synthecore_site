## Важные ограничения

- Скриншоты и автономный HTML получены с fallback **Inter**, так как Manrope из Google Fonts при локальном просмотре может быть недоступен. В исходном v61 CSS прописан `Manrope` с fallback; итоговая метрика текста при фактической загрузке Manrope может отличаться.
- Браузерное тестирование здесь основано на автономном документе с инлайновыми локальными ресурсами, **а не на запуске через production-сервер**. Не выдавать это за полную приёмку развернутого сайта.
- Для GSAP sticky/ScrollTrigger проверены отсутствие ошибок и сохранность скриптов, но **полный покадровый просмотр всех стадий прокрутки, iOS Safari и реальная производительность 4K не утверждаются**.
- Демонстрационные отзывы сохранены; перед публикацией их нужно заменить подтвержденными.
- При утверждении дизайн-системы понадобится принять решение о Manrope (внешняя загрузка шрифта против локального лицензированного размещения).
